= Gérez les événements et les alertes à l'aide des API dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les `events`, `alerts` et `scripts` API de la catégorie `management-server` vous permettent de gérer les événements, les alertes et les scripts associés aux alertes dans votre environnement Active IQ Unified Manager.



[[view-and-modify-events]]
== Afficher et modifier les événements

Unified Manager reçoit les événements générés sur ONTAP pour les clusters qu'il surveille et gère. Grâce à ces API, vous pouvez consulter, résoudre et mettre à jour les événements générés pour vos clusters.

En exécutant la `GET` méthode de l' `/management-server/events`API, vous pouvez interroger les événements de votre centre de données, y compris les données historiques. Utilisez les filtres intégrés, tels que le nom, le niveau d'impact, la zone d'impact, la gravité, l'état, le nom de la ressource et le type de ressource, pour afficher des événements spécifiques. Les paramètres de type de ressource et de zone renvoient des informations sur l'objet de stockage sur lequel l'événement s'est produit, et la zone d'impact renvoie des informations sur le problème pour lequel l'événement est généré, comme la disponibilité, la capacité, la configuration, la sécurité, la protection et les performances.

En exécutant l'opération PATCH pour cette API, vous pouvez activer le workflow de résolution pour l'événement. Vous pouvez vous attribuer un événement ou l'attribuer à un autre utilisateur et en accuser réception. Après avoir effectué les étapes nécessaires sur les ressources pour résoudre le problème qui a déclenché l'événement, vous pouvez utiliser cette API pour marquer l'événement comme résolu.

Pour plus d'informations sur les événements, voir link:../events/concept_what_active_iq_platform_events_are.html["Découvrez les événements de la plateforme Active IQ"].

[cols="4*"]
|===
| Catégorie | Verbe HTTP | Chemin | Description 


 a| 
serveur de gestion
 a| 
GET
 a| 
`/management-server/events`
`/management-server/events/{key}`
 a| 
Lorsque vous exécutez la méthode Get ALL, le corps de la réponse contient les détails de tous les événements de votre centre de données. Lorsque vous récupérez les détails d'un événement à l'aide d'une clé spécifique, vous pouvez consulter les informations relatives à un événement particulier et exécuter les opérations suivantes sur les ressources. Le corps de la réponse contient alors les détails de cet événement.



 a| 
serveur de gestion
 a| 
CORRECTIF
 a| 
`management-server/events/{key}`
 a| 
Utilisez cette API pour attribuer un événement ou modifier son état en accusé de réception ou résolu. Vous pouvez également l'utiliser pour vous attribuer l'événement ou l'attribuer à un autre utilisateur. Il s'agit d'une opération synchrone.

|===


[[manage-alerts]]
== Gérer les alertes

Les événements sont générés automatiquement et en continu. Unified Manager génère une alerte uniquement lorsqu'un événement répond à certains critères de filtrage. Vous pouvez sélectionner les événements pour lesquels des alertes doivent être générées. En utilisant l' `/management-server/alerts`API, vous pouvez configurer des alertes pour envoyer automatiquement des notifications lorsque des événements spécifiques ou des événements de certains niveaux de gravité se produisent.

Pour plus d'informations sur les alertes, consultez link:../events/concept_what_alerts_are.html["Découvrez les alertes"].

[cols="4*"]
|===
| Catégorie | Verbe HTTP | Chemin | Description 


 a| 
serveur de gestion
 a| 
GET
 a| 
`/management-server/alerts`
`/management-server/alerts/{key}`
 a| 
Consultez toutes les alertes existantes dans votre environnement ou une alerte spécifique à l'aide de la clé d'alerte. Vous pouvez visualiser les informations relatives aux alertes générées dans votre environnement, telles que la description, l'action, l'adresse e-mail de notification, l'événement et le niveau de gravité.



 a| 
serveur de gestion
 a| 
POST
 a| 
`/management-server/alerts`
 a| 
Cette méthode vous permet d'ajouter des alertes pour des événements spécifiques. Vous devez ajouter le nom de l'alerte, la ressource physique ou logique, ou l'événement auquel l'alerte s'applique, indiquer si l'alerte est activée et si vous émettez des traps SNMP. Vous pouvez ajouter des détails supplémentaires pour lesquels vous souhaitez générer l'alerte, tels que l'action, l'adresse e-mail de notification, les détails du script, si vous ajoutez un script d'alerte, etc.



 a| 
serveur de gestion
 a| 
PATCH et DELETE
 a| 
`management-server/events/{key}`
 a| 
Vous pouvez utiliser ces méthodes pour modifier et supprimer des alertes spécifiques. Vous pouvez modifier différents attributs, tels que la description, le nom et l'activation ou la désactivation de l'alerte. Vous pouvez supprimer une alerte lorsqu'elle n'est plus nécessaire.

|===

NOTE: Lors de la sélection d'une ressource pour l'ajout d'une alerte, veuillez noter que la sélection d'un cluster ne sélectionne pas automatiquement les objets de stockage qu'il contient. Par exemple, si vous créez une alerte pour tous les événements critiques de tous les clusters, vous ne recevrez d'alertes que pour les événements critiques des clusters. Vous ne recevrez pas d'alertes pour les événements critiques sur les nœuds, les agrégats, etc.



[[manage-scripts]]
== Gérer les scripts

Grâce à l' `/management-server/scripts`API, vous pouvez également associer une alerte à un script qui s'exécute lorsqu'une alerte est déclenchée. Vous pouvez utiliser des scripts pour modifier ou mettre à jour automatiquement plusieurs objets de stockage dans Unified Manager. Le script est associé à une alerte. Lorsqu'un événement déclenche une alerte, le script s'exécute. Vous pouvez charger des scripts personnalisés et tester leur exécution lorsqu'une alerte est générée. Vous pouvez associer une alerte à votre script afin que celui-ci s'exécute lorsqu'une alerte est déclenchée pour un événement dans Unified Manager.

Pour plus d'informations sur les scripts, voir link:../events/concept_manage_scripts.html["Gérer les scripts"].

 a|

 a| 
`/management-server/scripts`

Utilisez cette API pour interroger tous les scripts existants dans votre environnement. Utilisez les fonctions de filtrage et de tri standard pour afficher uniquement les scripts souhaités.



 a| 
serveur de gestion
 a| 
POST
 a| 
`/management-server/scripts`
 a| 
Utilisez cette API pour ajouter une description au script et télécharger le fichier de script associé à une alerte.
