= Gérez les mappages Active Directory à l'aide des API dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez utiliser les API listées ici pour gérer les mappages Active Directory sur la SVM, nécessaires au provisionnement des partages CIFS sur les SVM. Ces mappages Active Directory doivent être configurés pour associer les SVM à ONTAP.



[[view-active-directory-mappings]]
== Afficher les mappages Active Directory

Vous pouvez consulter les détails de configuration des mappages Active Directory d'une SVM en procédant comme suit. Pour afficher les mappages Active Directory sur une SVM, vous devez saisir la clé SVM. Pour interroger les détails d'un mappage particulier, vous devez saisir la clé du mappage.

[cols="3*"]
|===
| Catégorie | Verbe HTTP | Chemin 


 a| 
fournisseur de stockage
 a| 
GET
 a| 
`/storage-provider/active-directories-mappings`

`/storage-provider/active-directories-mappings/\{key}`

|===


[[add-active-directory-mapping]]
== Ajouter un mappage Active Directory

Vous pouvez créer des mappages Active Directory sur une SVM en utilisant la méthode suivante. Vous devez saisir les détails du mappage en tant que paramètres d'entrée.

[cols="3*"]
|===
| Catégorie | Verbe HTTP | Chemin 


 a| 
fournisseur de stockage
 a| 
POST
 a| 
`/storage-provider/active-directories-mappings`

|===
