= Vérifiez les SVM sur les clusters ONTAP à l'aide des API d'Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Avant de provisionner des partages de fichiers ou des LUN, vous devez vérifier si des machines virtuelles de stockage (SVM) ont été créées sur les clusters.

[NOTE]
====
Le workflow suppose que les clusters ONTAP ont été ajoutés à Unified Manager et que la clé du cluster a été obtenue. Les clusters doivent disposer des licences requises pour le provisionnement des LUN et des partages de fichiers sur ceux-ci.

====
. Vérifiez si une SVM a été créée dans le cluster.
+
[cols="3*"]
|===
| Catégorie | Verbe HTTP | Chemin 


 a| 
centre de données
 a| 
GET
 a| 
`/datacenter/svm/svms`
`/datacenter/svm/svms/\{key}`

|===
+
*Exemple de cURL*

+
[listing]
----
curl -X GET "https://<hostname>/api/datacenter/svm/svms" -H "accept: application/json" -H "Authorization: Basic <Base64EncodedCredentials>"
----
. Si la clé SVM n'est pas renvoyée, créez la SVM. Pour créer les SVM, vous avez besoin de la clé du cluster sur lequel vous provisionnez la SVM. Vous devez également spécifier le nom de la SVM. Suivez ces étapes.
+
[cols="3*"]
|===
| Catégorie | Verbe HTTP | Chemin 


 a| 
centre de données
 a| 
GET
 a| 
`/datacenter/cluster/clusters`
`/datacenter/cluster/clusters/\{key}`

|===
+
Obtenez la clé du cluster.

+
*Exemple de cURL*

+
[listing]
----
curl -X GET "https://<hostname>/api/datacenter/cluster/clusters" -H "accept: application/json" -H "Authorization: Basic <Base64EncodedCredentials>"
----
. À partir du résultat, récupérez la clé du cluster, puis utilisez-la comme valeur d'entrée pour créer le SVM.
+
[NOTE]
====
Lors de la création de la SVM, assurez-vous qu'elle prend en charge tous les protocoles nécessaires au provisionnement des LUN et des partages de fichiers, tels que CIFS, NFS, FCP et iSCSI. Les processus de provisionnement risquent d'échouer si la SVM ne prend pas en charge les services requis. Il est recommandé d'activer également sur la SVM les services correspondant aux types de charges de travail concernés.

====
+

|===
