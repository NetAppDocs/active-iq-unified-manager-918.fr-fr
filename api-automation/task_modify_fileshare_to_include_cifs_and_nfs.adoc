= Modifier un partage de fichiers NFS pour prendre en charge CIFS à l'aide des API d'Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez modifier un partage de fichiers NFS pour qu'il prenne en charge le protocole CIFS. Lors de la création d'un partage de fichiers, il est possible de spécifier à la fois les paramètres de liste de contrôle d'accès (ACL) et les règles d'export pour le même partage de fichiers. Toutefois, si vous souhaitez activer CIFS sur le même volume que celui où vous avez créé un partage de fichiers NFS, vous pouvez mettre à jour les paramètres ACL de ce partage de fichiers pour prendre en charge CIFS.

.Avant de commencer
. Un partage de fichiers NFS doit avoir été créé avec uniquement les détails des règles d'export. Pour plus d'informations, consultez les sections _Gestion des partages de fichiers_ et _Modification des charges de travail de stockage_.
. Vous devez disposer de la clé de partage de fichiers pour exécuter cette opération. Pour plus d'informations sur la consultation des détails du partage de fichiers et la récupération de la clé de partage de fichiers à l'aide de l'ID de tâche, consultez _Provisioning CIFS and NFS file shares_.


Ceci s'applique à un partage de fichiers NFS que vous avez créé en ajoutant uniquement des règles d'export et non des paramètres ACL. Vous modifiez le partage de fichiers NFS pour y inclure les paramètres ACL.

.Étapes
. Sur le partage de fichiers NFS, effectuez une `PATCH` opération avec les détails de l'ACL pour autoriser l'accès CIFS.
+
[cols="3*"]
|===
| Catégorie | Verbe HTTP | Chemin 


 a| 
fournisseur de stockage
 a| 
CORRECTIF
 a| 
`/storage-provider/file-shares`

|===
+
*Exemple de cURL*

+
En fonction des privilèges d'accès que vous attribuez au groupe d'utilisateurs, comme illustré dans l'exemple suivant, une liste de contrôle d'accès (ACL) est créée et attribuée au partage de fichiers.

+
[listing]
----
{
  "access_control": {
    "acl": [
      {
        "permission": "read",
        "user_or_group": "everyone"
      }
    ],
    "active_directory_mapping": {
      "key": "3b648c1b-d965-03b7-20da-61b791a6263c"
    }
----
+
*Exemple de sortie JSON*

+
L'opération renvoie le Job ID du Job qui exécute la mise à jour.

. Vérifiez si les paramètres ont été correctement ajoutés en consultant les détails du partage de fichiers correspondant.
