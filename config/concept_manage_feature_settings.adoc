= Découvrez les paramètres des fonctionnalités dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La page Paramètres des fonctionnalités vous permet d'activer et de désactiver des fonctionnalités spécifiques dans Active IQ Unified Manager. Vous pouvez notamment créer et gérer des objets de stockage en fonction de stratégies, activer la passerelle API et la bannière de connexion, charger des scripts pour gérer les alertes, configurer l'expiration automatique d'une session de l'interface Web en cas d'inactivité et désactiver la réception des événements de la plateforme Active IQ.

[NOTE]
====
La page Feature Settings est uniquement accessible aux utilisateurs ayant le rôle Application Administrator.

====
Pour plus d'informations sur Scripts Upload, consultez link:task_enable_and_disable_ability_to_upload_scripts.html["Activation et désactivation du téléchargement de scripts"].
