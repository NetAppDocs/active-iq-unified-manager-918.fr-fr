= Fonctionnalités de diagnostic utilisateur dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
L’accès aux diagnostics a pour but de permettre au support technique de vous aider à résoudre les problèmes, et vous ne devez l’utiliser que sur instruction du support technique.

L'utilisateur de diagnostic peut exécuter des commandes au niveau du système d'exploitation sur instruction du support technique, à des fins de dépannage.
