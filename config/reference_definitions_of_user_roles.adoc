= Découvrez les rôles des utilisateurs dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
L'utilisateur en charge de la maintenance ou l'Application Administrator attribue un rôle à chaque utilisateur. Chaque rôle confère des privilèges spécifiques. L'étendue des actions que vous pouvez effectuer dans Unified Manager dépend du rôle qui vous est attribué et des privilèges associés.

Unified Manager inclut les rôles d'utilisateur prédéfinis suivants :

* *Opérateur*
+
Permet de consulter les informations du système de stockage et les autres données collectées par Unified Manager, notamment les historiques et les tendances de capacité. Ce rôle permet à l'opérateur de stockage de consulter, d'attribuer, d'acquitter, de résoudre et d'ajouter des notes aux événements.

* *Administrateur de stockage*
+
Configure les opérations de gestion du stockage dans Unified Manager. Ce rôle permet à l'administrateur du stockage de configurer les seuils et de créer des alertes ainsi que d'autres options et politiques spécifiques à la gestion du stockage.

* *Administrateur d'applications*
+
Configure les paramètres non liés à la gestion du stockage. Ce rôle permet la gestion des utilisateurs, des certificats de sécurité, de l'accès à la base de données et des options d'administration, notamment l'authentification, SMTP, la mise en réseau et AutoSupport.

+
[NOTE]
====
Lors de l'installation de Unified Manager sur les systèmes Linux, l'utilisateur initial doté du rôle Application Administrator est automatiquement nommé "`umadmin`".

====
* *Schéma d'intégration*
+
Ce rôle permet un accès en lecture seule aux vues de la base de données Unified Manager pour intégrer Unified Manager à OnCommand Workflow Automation (WFA).

* *Schéma du rapport*
+
Ce rôle permet un accès en lecture seule aux rapports et aux autres vues de la base de données directement depuis la base de données Unified Manager. Les bases de données consultables sont les suivantes :

+
** netapp_model_view
** netapp_performance
** ocum
** ocum_report
** ocum_report_birt
** opm
** scalemonitor
