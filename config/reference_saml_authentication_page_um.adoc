= Utilisez la page d'authentification SAML dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez utiliser la page d'authentification SAML pour configurer Unified Manager afin d'authentifier les utilisateurs distants à l'aide de SAML via un fournisseur d'identité sécurisé (IdP) avant qu'ils puissent se connecter à l'interface utilisateur web d'Unified Manager.

* Vous devez disposer du rôle d'administrateur d'application pour créer ou modifier la configuration SAML.
* Vous devez avoir configuré l'authentification à distance.
* Vous devez avoir configuré au moins un utilisateur distant ou un groupe distant.


Une fois l'authentification à distance et les utilisateurs distants configurés, vous pouvez cocher la case « Activer l'authentification SAML » pour activer l'authentification à l'aide d'un fournisseur d'identité sécurisé.

* *URI du fournisseur d'identité*
+
L'URI permettant d'accéder à l'IdP depuis le serveur Unified Manager. Des exemples d'URI sont fournis ci-dessous.

+
Exemple d'URI ADFS :

+
`+https://win2016-dc.ntap2016.local/federationmetadata/2007-06/federationmetadata.xml+`

+
Exemple d'URI Shibboleth:

+
`+https://centos7.ntap2016.local/idp/shibboleth+`

* *Métadonnées du fournisseur d'identité*
+
Les métadonnées du fournisseur d'identité au format XML.

+
Si l’URL IdP est accessible depuis le serveur Unified Manager, vous pouvez cliquer sur le bouton *Fetch IdP Metadata* pour renseigner ce champ.

* *Système hôte (FQDN)*
+
Le nom de domaine complet (FQDN) du système hôte d'Unified Manager, tel que défini lors de l'installation. Vous pouvez modifier cette valeur si nécessaire.

* *URI de l'hôte*
+
L'URI permettant d'accéder au système hôte Unified Manager depuis l'IdP.

* *Métadonnées de l'hôte*
+
Les métadonnées du système hôte au format XML.
