= Accédez à l'interface utilisateur Web dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Une fois Unified Manager installé, vous pouvez accéder à l’interface utilisateur Web pour configurer Unified Manager et commencer à surveiller vos systèmes ONTAP.

.Avant de commencer
* Si c'est la première fois que vous accédez à l'interface utilisateur Web, vous devez vous connecter en tant qu'utilisateur de maintenance (ou utilisateur umadmin pour les installations Linux).
* Si vous prévoyez d’autoriser les utilisateurs à accéder à Unified Manager en utilisant le nom court au lieu du domaine complet (FQDN) ou de l’adresse IP, votre configuration réseau doit résoudre ce nom court en un FQDN valide.
* Si le serveur utilise un certificat numérique auto-signé, le navigateur peut afficher un avertissement indiquant que le certificat n'est pas fiable. Vous pouvez soit accepter le risque pour continuer l'accès, soit installer un certificat numérique signé par une autorité de certification (AC) pour l'authentification du serveur.


.Étapes
. Démarrez l’interface utilisateur web de Unified Manager depuis votre navigateur en utilisant l’URL affichée à la fin de l’installation. L’URL correspond à l’adresse IP ou au domaine complet (FQDN) du serveur Unified Manager.
+
Le lien est au format suivant : `\https://URL`.

. Connectez-vous à l'interface web de Unified Manager en utilisant vos identifiants d'utilisateur de maintenance.



NOTE: Si vous effectuez trois tentatives consécutives infructueuses de connexion à l’interface utilisateur web dans un délai d’une heure, l’accès au système vous sera refusé et vous devrez contacter votre administrateur système. Cela s’applique uniquement aux utilisateurs locaux.
