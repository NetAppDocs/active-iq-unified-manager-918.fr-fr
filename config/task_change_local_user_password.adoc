= Modifiez le mot de passe de l'utilisateur local dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez modifier votre mot de passe de connexion utilisateur local afin de prévenir d'éventuels risques de sécurité.

.Avant de commencer
Vous devez être connecté en tant qu'utilisateur local.

Les mots de passe de l'utilisateur de maintenance et des utilisateurs distants ne peuvent pas être modifiés en suivant ces étapes. Pour modifier le mot de passe d'un utilisateur distant, contactez votre administrateur de mots de passe. Pour modifier le mot de passe de l'utilisateur de maintenance, consultez link:task_use_maintenance_console.html["Utilisation de la console de maintenance"].

.Étapes
. Connectez-vous à Unified Manager.
. Dans la barre de menu supérieure, cliquez sur l'icône d'utilisateur, puis sur *Changer le mot de passe*.
+
L'option *Changer le mot de passe* ne s'affiche pas si vous êtes un utilisateur distant.

. Dans la boîte de dialogue « Changer le mot de passe », saisissez le mot de passe actuel et le nouveau mot de passe.
. Cliquez sur *Enregistrer*.


Si Unified Manager est configuré dans une configuration haute disponibilité, vous devez modifier le mot de passe sur le second nœud de la configuration. Les deux instances doivent avoir le même mot de passe.
