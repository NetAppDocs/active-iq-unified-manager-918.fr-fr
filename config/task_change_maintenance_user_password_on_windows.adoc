= Modifiez le mot de passe de l'utilisateur de maintenance sous Windows dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez modifier le mot de passe de l'utilisateur de maintenance d'Unified Manager en cas de besoin.

.Étapes
. Depuis la page de connexion de l'interface utilisateur Web de Unified Manager, cliquez sur *Mot de passe oublié*.
+
Une page s'affiche et vous demande le nom de l'utilisateur dont vous souhaitez réinitialiser le mot de passe.

. Saisissez le nom d'utilisateur et cliquez sur *Soumettre*.
+
Un courriel contenant un lien pour réinitialiser le mot de passe est envoyé à l'adresse électronique définie pour ce nom d'utilisateur.

. Cliquez sur le lien *de réinitialisation du mot de passe* dans l'e-mail et définissez le nouveau mot de passe.
. Retournez à l’interface web et connectez-vous à Unified Manager à l’aide du nouveau mot de passe.
