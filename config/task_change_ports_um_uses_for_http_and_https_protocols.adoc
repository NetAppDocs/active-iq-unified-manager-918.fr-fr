= Modifier les ports qu'Active IQ Unified Manager utilise pour les protocoles HTTP et HTTPS
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les ports par défaut utilisés par Unified Manager pour les protocoles HTTP et HTTPS peuvent être modifiés après l'installation si nécessaire pour des raisons de sécurité. Les ports par défaut sont 80 pour HTTP et 443 pour HTTPS.

.Avant de commencer
Vous devez disposer d'un identifiant utilisateur et d'un mot de passe autorisés pour vous connecter à la console de maintenance du serveur Unified Manager.

[NOTE]
====
Certains ports sont considérés comme non sécurisés lors de l'utilisation des navigateurs Mozilla Firefox ou Google Chrome. Consultez votre navigateur avant d'attribuer un nouveau numéro de port pour le trafic HTTP et HTTPS. Le choix d'un port non sécurisé pourrait rendre le système inaccessible, ce qui vous obligerait à contacter le support client pour résoudre le problème.

====
L'instance d'Unified Manager redémarre automatiquement après la modification du port ; assurez-vous donc que c'est le bon moment pour arrêter brièvement le système.

. Connectez-vous à l’hôte Unified Manager via SSH en tant qu’utilisateur de maintenance.
+
Les invites de la console de maintenance Unified Manager s'affichent.

. Saisissez le numéro de l'option de menu intitulée *Afficher/Modifier les ports d'application*, puis appuyez sur Entrée.
. Si vous y êtes invité, saisissez à nouveau le mot de passe de l'utilisateur de maintenance.
. Saisissez les nouveaux numéros de port pour les ports HTTP et HTTPS, puis appuyez sur Entrée.
+
Laisser le numéro de port vide attribue le port par défaut pour le protocole.

+
Il vous est demandé si vous souhaitez modifier les ports et redémarrer Unified Manager maintenant.

. Tapez *y* pour modifier les ports et redémarrer Unified Manager.
. Quittez la console de maintenance.


Après cette modification, les utilisateurs doivent inclure le nouveau numéro de port dans l'URL pour accéder à l'interface utilisateur Web de Unified Manager, par exemple +https://host.company.com:1234+, +https://12.13.14.15:1122+, ou +https://[2001:db8:0:1]:2123+.
