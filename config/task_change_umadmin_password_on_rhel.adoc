= Modifiez le mot de passe umadmin d'Active IQ Unified Manager sur les systèmes Linux
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Pour des raisons de sécurité, vous devez modifier le mot de passe par défaut de l’utilisateur umadmin de Unified Manager immédiatement après avoir terminé le processus d’installation. Si nécessaire, vous pourrez modifier à nouveau le mot de passe ultérieurement.

.Avant de commencer
* Unified Manager doit être installé sur un système Red Hat Enterprise Linux.
* Vous devez disposer des identifiants de l'utilisateur root pour le système Linux sur lequel Unified Manager est installé.


.Étapes
. Connectez-vous en tant qu'utilisateur root au système Linux sur lequel Unified Manager s'exécute.
. Modifier le mot de passe umadmin:
+
`passwd umadmin`

+
Le système vous invite à saisir un nouveau mot de passe pour l'utilisateur umadmin.
