= Activer la journalisation à distance des journaux d'audit dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez cocher la case *Enable Remote Logging* dans la boîte de dialogue Configure Audit Logs pour activer la journalisation à distance. Vous pouvez utiliser cette fonctionnalité pour transférer les journaux des audits vers un serveur Syslog distant. Cela vous permettra de gérer vos journaux des audits en cas de contraintes d’espace.

La journalisation à distance des journaux des audits fournit une sauvegarde inviolable au cas où les fichiers du journal des audits sur le serveur Active IQ Unified Manager seraient altérés.

.Étapes
. Dans la boîte de dialogue *Configurer les journaux des audits*, cochez la case *Activer la journalisation à distance*.
+
Des champs supplémentaires pour configurer la journalisation à distance s'affichent.

. Saisissez le *nom de l'hôte* et le *PORT* du serveur distant auquel vous souhaitez vous connecter.
. Dans le champ *CERTIFICAT D'AC DU SERVEUR*, cliquez sur *PARCOURIR* pour sélectionner un certificat public du serveur cible.
+
Le certificat doit être téléchargé au format  `.pem`. Ce certificat doit être obtenu à partir du serveur Syslog cible et ne doit pas avoir expiré. Le certificat doit contenir le "`hostname`" sélectionné dans l'attribut  `SubjectAltName` (SAN).

. Saisissez les valeurs pour les champs suivants : *CHARSET*, *CONNECTION TIMEOUT*, *RECONNECTION DELAY*.
+
Les valeurs de ces champs doivent être exprimées en millisecondes.

. Sélectionnez le format Syslog requis et la version requise du protocole TLS dans les champs *FORMAT* et *PROTOCOL*.
. Cochez la case *Activer l'authentification de clients* si le serveur Syslog cible requiert une authentification basée sur des certificats.
+
Vous devrez télécharger le certificat d'authentification de clients et le charger sur le serveur Syslog avant d'enregistrer la configuration du journal d'audit, sinon la connexion échouera. Selon le type de serveur Syslog, vous devrez peut-être créer un hachage du certificat d'authentification de clients.

+
Exemple : syslog-ng exige qu’un <hash> du certificat soit créé à l’aide de la commande `openssl x509 -noout -hash -in cert.pem`, puis vous devez créer un lien symbolique vers le certificat d’authentification de clients dans un fichier nommé d’après le <hash> .0.

. Cliquez sur *Enregistrer* pour configurer la connexion avec votre serveur et activer la journalisation à distance.
+
Vous serez redirigé vers la page des journaux d'audit.

+
[NOTE]
====
La valeur de *Connection Timeout* peut affecter la configuration. Si la configuration met plus de temps à répondre que la valeur définie, cela peut entraîner un échec de la configuration en raison d'une erreur de connexion. Pour établir une connexion réussie, augmentez la valeur de *Connection Timeout* et réessayez la configuration.
