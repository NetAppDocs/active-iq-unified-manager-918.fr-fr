= Utilisez la boîte de dialogue des agrégats dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez utiliser la boîte de dialogue Aggregates pour sélectionner les agrégats que vous souhaitez ajouter à votre pool de ressources.



[[command-buttons]]
== Boutons de commande

Les boutons de commande vous permettent d'effectuer les tâches suivantes :

* *Ajouter*
+
Ajoute les agrégats sélectionnés au pool de ressources. Le bouton Ajouter n'est activé que lorsqu'au moins un agrégat est sélectionné.

* *Annuler*
+
Annule les modifications et ferme la boîte de dialogue Agrégats.





[[aggregates-list]]
== Liste des agrégats

La liste des agrégats affiche (sous forme de tableau) les noms et les propriétés des agrégats surveillés.

* *Statut*
+
Affiche l'état actuel d'un volume. L'état peut être Critique (image:../media/sev_critical_um60.png[""]), Erreur (image:../media/sev_error_um60.png[""]), Avertissement (image:../media/sev_warning_um60.png[""]) ou Normal (image:../media/sev_normal_um60.png[""]).

+
Vous pouvez placer le pointeur sur l’état pour afficher plus d’informations sur l’événement ou les événements générés pour le volume.

* *Nom de l'agrégat*
+
Affiche le nom de l'agrégat.

* *État*
+
Affiche l'état actuel de l'agrégat, qui peut être l'un des suivants :

+
** Hors ligne
+
L'accès en lecture ou en écriture n'est pas autorisé.

** Restreint
+
Les opérations limitées (telles que la reconstruction de la parité) sont autorisées, mais l'accès aux données n'est pas autorisé.

** En ligne
+
L'accès en lecture et en écriture aux volumes hébergés sur cet agrégat est autorisé.

** Création
+
L'agrégat est en cours de création.

** Destruction en cours
+
L'agrégat est en cours de destruction.

** Échec
+
L'agrégat ne peut pas être mis en ligne.

** Gelé
+
L’agrégat ne traite pas (temporairement) les requêtes.

** Incohérent
+
L'agrégat a été marqué comme corrompu; vous devriez contacter le support technique.

** Restriction du fer
+
Les outils de diagnostic ne peuvent pas être exécutés sur l'agrégat.

** Montage
+
L'agrégat est en cours de montage.

** Partiel
+
Au moins un disque a été trouvé pour l’agrégat, mais deux disques ou plus sont manquants.

** Suspension
+
L’agrégat est en cours de mise au repos.

** Suspendu
+
L’agrégat est au repos.

** Rétabli
+
Le retour à une version antérieure d'un agrégat est terminé.

** Non monté
+
L'agrégat est hors ligne.

** Démontage
+
L'agrégat est en cours de mise hors ligne.

** Inconnu
+
L'agrégat est détecté, mais le serveur Unified Manager n'a pas encore récupéré les informations sur l'agrégat.



* *Cluster*
+
Affiche le nom du cluster sur lequel réside l'agrégat.

* *Nœud*
+
Affiche le nom du contrôleur de stockage qui contient l'agrégat.

* *Capacité totale*
+
Affiche la taille totale des données (en Mo, Go, etc.) de l'agrégat. Cette colonne est masquée par défaut.

* *Capacité engagée*
+
Affiche l'espace total (en Mo, Go, etc.) alloué à l'ensemble des volumes dans l'agrégat. Cette colonne est masquée par défaut.

* *Capacité utilisée*
+
Affiche la quantité d'espace (en Mo, Go, etc.) utilisée dans l'agrégat.

* *Capacité disponible*
+
Affiche la quantité d’espace (en Mo, Go, etc.) disponible pour les données dans l’agrégat. Cette colonne est masquée par défaut.

* *Disponible %*
+
Affiche le pourcentage d'espace disponible pour les données dans l'agrégat. Par défaut, cette colonne est masquée.

* *% utilisé*
+
Affiche le pourcentage d'espace utilisé par les données dans l'agrégat.

* *Type de RAID*
+
Affiche le type RAID du volume sélectionné. Le type RAID peut être RAID0, RAID4, RAID-DP, RAID-TEC ou RAID mixte.
