= Utilisez la boîte de dialogue Créer un pool de ressources dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez utiliser la boîte de dialogue Créer un pool de ressources pour nommer et décrire un nouveau pool de ressources, ainsi que pour ajouter et supprimer des agrégats de ce pool de ressources.



[[resource-pool-name]]
== Nom du pool de ressources

Les zones de texte vous permettent d'ajouter les informations suivantes pour créer un pool de ressources :

Permet de spécifier un nom de pool de ressources.



[[description]]
== Description

Permet de décrire un pool de ressources.



[[members]]
== Membres

Affiche les membres du pool de ressources. Vous pouvez également ajouter et supprimer des membres.



[[command-buttons]]
== Boutons de commande

Les boutons de commande vous permettent d'effectuer les tâches suivantes :

* *Ajouter*
+
Ouvre la boîte de dialogue Agrégats pour vous permettre d'ajouter des agrégats d'un cluster spécifique au pool de ressources. Vous pouvez ajouter des agrégats provenant de différents clusters, mais un même agrégat ne peut pas être ajouté à plusieurs pools de ressources.

* *Retirer*
+
Permet de supprimer les agrégats sélectionnés du pool de ressources.

* *Créer*
+
Crée le pool de ressources. Ce bouton n'est pas activé tant que des informations n'ont pas été saisies dans les champs Nom du pool de ressources ou Description.

* *Annuler*
+
Annule les modifications et ferme la boîte de dialogue Créer un pool de ressources.
