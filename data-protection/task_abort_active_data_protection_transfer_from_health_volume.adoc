= Annuler un transfert depuis la page Détails du volume/de l’état dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez interrompre un transfert de protection des données actif lorsque vous souhaitez arrêter une réplication SnapMirror en cours. Vous pouvez également effacer le point de contrôle de redémarrage d'un transfert s'il ne s'agit pas d'un transfert de base. Vous pouvez aussi interrompre un transfert s'il entre en conflit avec une autre opération, comme un déplacement de volume.

[NOTE]
====
Vous ne pouvez pas interrompre les relations de volume protégées par le groupe de cohérence.

====
.Avant de commencer
* Vous devez disposer du rôle Application Administrator ou Storage Administrator.
* Vous devez avoir configuré Workflow Automation.


L'option d'annulation ne s'affiche pas dans les cas suivants :

* Si les paramètres RBAC ne permettent pas cette action: par exemple, si vous ne disposez que de privilèges d’opérateur
* Lorsque l'ID du volume est inconnu : par exemple, lorsque vous avez une relation intercluster et que le cluster de destination n'a pas encore été découvert


Vous ne pouvez pas effacer le point de contrôle de redémarrage pour un transfert de base.

.Étapes
. Dans l'onglet *Protection* de la page de détails *Volume / Health*, cliquez avec le bouton droit sur la relation dans la vue topologique correspondant au transfert de données que vous souhaitez abandonner, puis sélectionnez *Abort*.
+
La boîte de dialogue « Annuler le transfert » s'affiche.

. Si vous souhaitez effacer le point de contrôle de redémarrage pour un transfert qui n'est pas un transfert de base, sélectionnez *Effacer les points de contrôle*.
. Cliquez sur *Continuer*.
+
La boîte de dialogue Annuler le transfert se ferme, et l'état de l'opération d'annulation s'affiche en haut de la page Détails du volume/de l'état, accompagné d'un lien vers les détails de la tâche.

. *Facultatif :* Cliquez sur le lien *View details* pour accéder à la page de détails du *Job* afin d’obtenir des informations supplémentaires et de consulter la progression du job.
. Cliquez sur chaque tâche pour en afficher les détails.
. Cliquez sur la flèche Retour de votre navigateur pour revenir à la page de détails *Volume / Health*.
+
L'opération d'annulation est terminée lorsque toutes les tâches du job sont accomplies avec succès.
