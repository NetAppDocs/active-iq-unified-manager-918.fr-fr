= Configurez une connexion entre Workflow Automation et Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez configurer une connexion sécurisée entre OnCommand Workflow Automation (WFA) et Unified Manager. La connexion à Workflow Automation vous permet d’utiliser des fonctionnalités de protection telles que les workflows de configuration SnapMirror et SnapVault, ainsi que des commandes pour gérer les relations SnapMirror.

.Avant de commencer
* La version installée de Workflow Automation doit être la version 5.1.1P6 ou une version ultérieure.
+
[NOTE]
====
Le « pack WFA pour la gestion de Clustered Data ONTAP » est inclus dans WFA 5.1.1P6, il n’est donc plus nécessaire de télécharger ce pack depuis le NetAppStorage Automation Store et de l’installer séparément sur votre serveur WFA comme c’était le cas auparavant. https://mysupport.netapp.com/site/products/all/details/ocwfa/downloads-tab["Téléchargement WFA"^]

====
* Vous devez disposer du nom de l'utilisateur de la base de données que vous avez créé dans Unified Manager pour prendre en charge les connexions WFA et Unified Manager.
+
Cet utilisateur de base de données doit s'être vu attribuer le rôle d'utilisateur « Integration Schema ».

* Le rôle d'administrateur ou d'architecte doit vous être attribué dans Workflow Automation.
* Vous devez disposer de l'adresse de l'hôte, du numéro de port 443, du nom d'utilisateur et du mot de passe pour la configuration de Workflow Automation.
* Vous devez disposer du rôle Application Administrator ou Storage Administrator.


.Étapes
. Dans le volet de navigation de gauche, cliquez sur *General* > *Workflow Automation*.
. Dans la zone *Utilisateur de la base de données* de la *page Workflow Automation*, sélectionnez le nom et saisissez le mot de passe de l'utilisateur de la base de données que vous avez créé pour prendre en charge les connexions à Unified Manager et à Workflow Automation.
. Dans la zone *Workflow Automation Credentials* de la page, saisissez le nom de l'hôte ou l'adresse IP (IPv4 ou IPv6), ainsi que le nom d'utilisateur et le mot de passe de la configuration Workflow Automation.
+
Vous devez utiliser le port du serveur Unified Manager (port 443).

. Cliquez sur *Enregistrer*.
. Si vous utilisez un certificat auto-signé, cliquez sur *Oui* pour autoriser le certificat de sécurité.
+
La page Workflow Automation s'affiche.

. Cliquez sur *Oui* pour recharger la web UI et ajouter les fonctionnalités de Workflow Automation.
