= Créez une relation SnapVault à partir de la vue Health: All Volumes dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez utiliser la vue « État : Tous les volumes » pour créer des relations SnapVault pour un ou plusieurs volumes sur la même machine virtuelle de stockage afin d’activer les sauvegardes de données à des fins de protection.

.Avant de commencer
* Vous devez disposer du rôle Application Administrator ou Storage Administrator.
* Vous devez avoir configuré Workflow Automation.


Le menu *Protection* ne s'affiche pas dans les cas suivants :

* Si les paramètres RBAC ne permettent pas cette action: par exemple, si vous ne disposez que de privilèges d’opérateur
* Lorsque l'ID du volume est inconnu : par exemple, lorsque vous avez une relation intercluster et que le cluster de destination n'a pas encore été découvert


.Étapes
. Dans le volet de navigation de gauche, cliquez sur *Stockage* > *Volumes*.
. Dans la vue *Santé : Tous les volumes*, sélectionnez un volume que vous souhaitez protéger et cliquez sur *Protéger*.
+
Vous pouvez également, pour créer plusieurs relations de protection sur la même machine virtuelle de stockage (SVM), sélectionner un ou plusieurs volumes dans la vue Santé : Tous les volumes, puis cliquer sur *Protéger* dans la barre d’outils.

. Sélectionnez *SnapVault* dans le menu.
+
La boîte de dialogue Configurer la protection s'affiche.

. Cliquez sur *SnapVault* pour afficher l'onglet *SnapVault* et configurer les informations du volume secondaire.
. Cliquez sur *Avancé* pour configurer la déduplication, la compression, l'extension automatique et la garantie d'espace selon vos besoins, puis cliquez sur *Appliquer*.
. Remplissez les zones *Informations sur la destination* et *Paramètres de la relation* dans l’onglet *SnapVault*.
. Cliquez sur *Appliquer*.
+
Vous revenez à la vue Santé: Tous les volumes.

. Cliquez sur le lien de la tâche de configuration de la protection en haut de la vue *Santé : Tous les volumes*.
+
Si vous ne créez qu'une seule relation de protection, la page Détails de la tâche s'affiche ; en revanche, si vous créez plusieurs relations de protection, une liste filtrée de toutes les tâches associées à l'opération de protection s'affiche.

. Effectuez l'une des opérations suivantes :
+
** Si vous n'avez qu'un seul travail, cliquez sur *Actualiser* pour mettre à jour la liste des tâches et les détails de la tâche associés au travail de configuration de la protection, et pour déterminer quand le travail est terminé.
** Si vous avez plus d'un emploi :
+
... Cliquez sur une tâche dans la liste des tâches.
... Cliquez sur *Actualiser* pour mettre à jour la liste des tâches et les détails des tâches associés au travail de configuration de la protection, et pour déterminer quand le travail est terminé.
... Utilisez le bouton *Retour* pour revenir à la liste filtrée et afficher une autre tâche.
