= Modifiez les relations de protection à partir de la page Détails du volume/de l’état dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez modifier les relations de protection existantes pour changer le débit de transfert maximal actuel, la politique de protection ou le calendrier de protection. Vous pouvez, par exemple, modifier une relation pour réduire la bande passante utilisée pour les transferts ou augmenter la fréquence des transferts planifiés si les données changent souvent.

.Avant de commencer
* Vous devez disposer du rôle Application Administrator ou Storage Administrator.
* Vous devez avoir installé et configuré Workflow Automation.


Les volumes sélectionnés doivent être des destinations de relations de protection. Vous ne pouvez pas modifier les relations lorsque des volumes sources, des volumes de partage de charge ou des volumes qui ne sont pas la destination d'une relation SnapMirror ou SnapVault sont sélectionnés.

.Étapes
. Dans l'onglet *Protection* de la page de détails *Volume / Health*, repérez dans la topologie la relation de protection que vous souhaitez modifier et cliquez dessus avec le bouton droit.
. Sélectionnez *Modifier* dans le menu.
+
Vous pouvez également, à partir du menu *Actions*, sélectionner *Relationship* > *Edit* pour modifier la relation dont vous consultez actuellement les détails.

+
La boîte de dialogue *Modifier la relation* s'affiche.

. Dans la boîte de dialogue Modifier la relation, modifiez le taux de transfert maximal, la politique de protection ou la planification de protection, selon vos besoins.
. Cliquez sur *Appliquer*.
+
Les modifications sont appliquées aux relations sélectionnées.
