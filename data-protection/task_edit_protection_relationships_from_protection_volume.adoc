= Modifiez les relations de protection à partir de la page Relations de volumes dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez modifier les relations de protection existantes pour changer le débit de transfert maximal, la stratégie de protection ou la planification de la protection. Vous pouvez par exemple modifier une relation pour réduire la bande passante utilisée pour les transferts ou augmenter la fréquence des transferts planifiés si les données évoluent fréquemment.

.Avant de commencer
Vous devez disposer du rôle Application Administrator ou Storage Administrator.

Les volumes sélectionnés doivent être des destinations de relations de protection. Vous ne pouvez pas modifier les relations lorsque des volumes sources, des volumes de partage de charge ou des volumes qui ne sont pas la destination d'une relation SnapMirror ou SnapVault sont sélectionnés.

.Étapes
. Sur la page *Relations entre volumes*, sélectionnez dans la liste des volumes un ou plusieurs volumes du même SVM pour lesquels vous souhaitez modifier les paramètres de relation, puis sélectionnez *Modifier* dans la barre d'outils.
+
La boîte de dialogue Modifier la relation s'affiche.

. Dans la boîte de dialogue *Modifier la relation*, modifiez le taux de transfert maximal, la politique de protection ou le calendrier de protection, selon vos besoins.
. Cliquez sur *Appliquer*.
+
Les modifications sont appliquées aux relations sélectionnées.
