= Supprimez une relation de protection depuis la page Détails du volume/de l’état dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez supprimer une relation de protection pour supprimer définitivement une relation existante entre la source et la destination sélectionnées : par exemple, lorsque vous souhaitez créer une relation avec une destination différente. Cette opération supprime toutes les métadonnées et est irréversible.

.Avant de commencer
* Vous devez disposer du rôle Application Administrator ou Storage Administrator.
* Vous devez avoir configuré Workflow Automation.


.Étapes
. Dans l'onglet *Protection* de la page de détails *Volume / Santé*, sélectionnez dans la topologie la relation SnapMirror que vous souhaitez supprimer.
. Faites un clic droit sur le nom de la destination et sélectionnez *Supprimer* dans le menu.
+
La boîte de dialogue Supprimer la relation s'affiche.

. Cliquez sur *Continuer* pour supprimer la relation.
+
La relation est supprimée de la page des détails Volume / Santé.
