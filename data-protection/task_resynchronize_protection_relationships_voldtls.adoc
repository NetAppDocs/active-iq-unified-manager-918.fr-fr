= Resynchronisez les relations de protection à partir de la page Détails du volume/de l’état dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez resynchroniser les données d’une relation SnapMirror ou SnapVault qui a été interrompue, puis rendre la destination accessible en lecture/écriture afin que les données de la source correspondent à celles de la destination. Vous pouvez également effectuer une resynchronisation lorsqu’une copie Snapshot commune requise sur le volume source est supprimée, entraînant l’échec des mises à jour SnapMirror ou SnapVault.

.Avant de commencer
* Vous devez disposer du rôle Application Administrator ou Storage Administrator.
* Vous devez avoir configuré OnCommand Workflow Automation.


.Étapes
. Dans l'onglet *Protection* de la page de détails *Volume / Santé*, repérez dans la topologie la relation de protection que vous souhaitez resynchroniser et cliquez dessus avec le bouton droit.
. Sélectionnez *Resynchronize* dans le menu.
+
Vous pouvez également, dans le menu *Actions*, sélectionner *Relation* > *Resynchroniser* pour resynchroniser la relation dont vous consultez actuellement les détails.

+
La boîte de dialogue Resynchroniser s'affiche.

. Dans l'onglet *Options de resynchronisation*, sélectionnez une priorité de transfert et le débit de transfert maximal.
. Cliquez sur *Copies d'instantané source*; puis, dans la colonne *Copie d'instantané*, cliquez sur *Par défaut*.
+
La boîte de dialogue « Sélectionner la copie d'instantané source » s'affiche.

. Si vous souhaitez spécifier une copie Snapshot existante plutôt que de transférer la copie Snapshot par défaut, cliquez sur *Copie Snapshot existante* et sélectionnez une copie Snapshot dans la liste.
. Cliquez sur *Submit*.
+
Vous revenez à la boîte de dialogue Resynchronize.

. Si vous avez sélectionné plusieurs sources à resynchroniser, cliquez sur *Default* pour la source suivante pour laquelle vous souhaitez spécifier une copie Snapshot existante.
. Cliquez sur *Submit* pour lancer la tâche de resynchronisation.
+
La tâche de resynchronisation démarre, vous revenez à la page Détails du volume / de l'état et un lien vers les tâches s'affiche en haut de la page.

. *Facultatif:* Cliquez sur *Afficher les tâches* dans la page *Détails du volume / de l’état* pour suivre l’état de chaque tâche de resynchronisation.
+
Une liste filtrée des tâches s'affiche.

. *Facultatif :* Cliquez sur la flèche *Retour* de votre navigateur pour revenir à la page de détails *Volume / Santé*.
+
Le travail de resynchronisation est terminé lorsque toutes les tâches du travail se terminent avec succès.
