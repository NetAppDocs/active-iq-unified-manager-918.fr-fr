= Réessayez une tâche de protection ayant échoué dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Après avoir pris les mesures nécessaires pour corriger une tâche de protection ayant échoué, vous pouvez utiliser *Réessayer* pour relancer la tâche. La réexécution d’une tâche crée une nouvelle tâche à l’aide de l’ID de tâche d’origine.

.Avant de commencer
Vous devez disposer du rôle Application Administrator ou Storage Administrator.

Vous ne pouvez relancer qu'une seule tâche ayant échoué à la fois. La sélection de plusieurs tâches désactive le bouton *Retry*. Seules les tâches de type Protection Configuration et Protection Relationship Operation peuvent être relancées.

.Étapes
. Dans le volet de navigation de gauche, cliquez sur *Protection* > *Tâches*.
. Dans la liste des tâches, sélectionnez une seule tâche ayant échoué de type Configuration de protection ou Opération de relation de protection.
+
Le bouton *Réessayer* est activé.

. Cliquez sur *Réessayer*.
+
La tâche est redémarrée.
