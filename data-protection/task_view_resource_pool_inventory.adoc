= Afficher l'inventaire du pool de ressources dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez utiliser la page Resource Pools pour consulter l'inventaire des pools de ressources et surveiller la capacité restante pour chaque pool de ressources.

.Avant de commencer
Vous devez disposer du rôle Application Administrator ou Storage Administrator.

.Étape
. Dans le volet de navigation de gauche, cliquez sur *Protection* > *Resource Pools*.
+
L'inventaire du pool de ressources est affiché.
