= Afficher les relations de protection des volumes dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Dans la vue « Relation : toutes les relations » et dans la page « Relations de volume », vous pouvez consulter l’état des relations SnapMirror et SnapVault du volume existant. Vous pouvez également examiner les détails des relations de protection, notamment l’état du transfert et du décalage, les informations sur la source et la destination, le calendrier et les informations sur la stratégie, etc.

.Avant de commencer
Vous devez disposer du rôle Application Administrator ou Storage Administrator.

Vous pouvez également lancer des commandes de relation à partir de cette page.

.Étapes
. Dans le volet de navigation de gauche, cliquez sur *Stockage* > *Volumes*.
. Dans le menu Affichage, sélectionnez *Relation* > *Toutes les relations*.
+
La vue « Relations : Toutes les relations » s’affiche.

. Choisissez l'une des méthodes suivantes pour afficher les détails de la protection du volume :
+
** Pour consulter les informations actuelles concernant toutes les relations de volume, restez sur la page par défaut *Toutes les relations*.
** Pour consulter des informations détaillées sur les tendances de transfert du volume au fil du temps, dans le menu Affichage, sélectionnez la vue Relation : État des transferts du dernier mois.
** Pour consulter des informations détaillées sur l'activité de transfert du volume au jour le jour, dans le menu Affichage, sélectionnez la vue Relation : Taux de transfert du dernier mois.


+
[NOTE]
====
Les vues de transfert de volume affichent des informations uniquement sur les volumes dans des relations asynchrones : les volumes dans des relations synchrones ne sont pas affichés.

====
