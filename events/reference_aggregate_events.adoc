= Découvrez les événements d'agrégat dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les événements d’agrégat vous fournissent des informations sur l’état des agrégats afin que vous puissiez surveiller les problèmes potentiels. Les événements sont regroupés par zone d’impact et comprennent le nom de l’événement et de l’interruption, le niveau d’impact, le type de source et la gravité.
