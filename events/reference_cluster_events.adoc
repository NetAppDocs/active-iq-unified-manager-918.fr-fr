= Découvrez les événements de cluster dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les événements de cluster fournissent des informations sur l'état des clusters, ce qui vous permet de les surveiller et de détecter d'éventuels problèmes. Ces événements sont regroupés par zone d'impact et comprennent le nom de l'événement, le nom du trap, le niveau d'impact, le type de source et la gravité.
