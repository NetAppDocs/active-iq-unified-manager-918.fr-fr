= Modifier les propriétés des alertes dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez modifier les propriétés de l'alerte, telles que la ressource à laquelle elle est associée, les événements, le script et les options de notification.



[[name]]
== Nom

Cette zone vous permet de modifier le nom et la description de l'alerte.

* *Nom de l'alerte*
+
Permet de modifier le nom de l'alerte.

* *Description de l'alerte*
+
Permet de spécifier une description pour l'alerte.

* *État d'alerte*
+
Permet d'activer ou de désactiver l'alerte.





[[resources]]
== Ressources

Cette zone vous permet de sélectionner une ressource individuelle ou de regrouper les ressources selon une règle dynamique pour laquelle vous souhaitez déclencher l'alerte. Vous pouvez rechercher des ressources en sélectionnant un type de ressource dans la liste déroulante ou en spécifiant le nom exact de la ressource pour afficher une ressource spécifique.

* *Inclure*
+
Permet d'inclure les ressources pour lesquelles vous souhaitez déclencher des alertes. Vous pouvez spécifier une chaîne de texte pour regrouper les ressources qui correspondent à cette chaîne et sélectionner ce groupe pour l'inclure dans l'alerte. Par exemple, vous pouvez regrouper tous les volumes dont le nom contient la chaîne "`vol0`".

* *Exclure*
+
Permet d'exclure les ressources pour lesquelles vous ne souhaitez pas déclencher d'alertes. Par exemple, vous pouvez exclure tous les volumes dont le nom contient la chaîne « `xyz` ».

+
[NOTE]
====
L'onglet Exclure s'affiche uniquement lorsque vous sélectionnez toutes les ressources d'un type de ressource particulier, par exemple, +<<All Volumes>>+ ou +<<All Volumes whose name contains 'xyz'>>+.

====




[[events]]
== Événements

Cette section vous permet de sélectionner les événements pour lesquels vous souhaitez déclencher les alertes. Vous pouvez déclencher une alerte pour des événements d'un certain niveau de gravité ou pour un ensemble d'événements.

* *Gravité de l'événement*
+
Permet de sélectionner les événements en fonction du type de gravité, qui peut être Critique, Erreur ou Avertissement.

* *Le nom de l'événement contient*
+
Permet de sélectionner les événements dont le nom contient les caractères spécifiés.





[[actions]]
== Actions

Cette zone vous permet de spécifier le mode de notification et la fréquence des notifications.

* *Alertez ces utilisateurs*
+
Permet de modifier l'adresse électronique ou le nom d'utilisateur, ou de spécifier une nouvelle adresse électronique ou un nouveau nom d'utilisateur pour recevoir des notifications.

* *Fréquence de notification*
+
Permet de modifier la fréquence à laquelle le serveur de gestion envoie des notifications jusqu'à ce que l'événement soit reconnu, résolu ou déplacé vers l'état obsolète.

+
Vous pouvez choisir les méthodes de notification suivantes :

+
** Notifier une seule fois
** Notifier à la fréquence spécifiée
** Notifier à une fréquence spécifiée dans la plage horaire spécifiée


* *Émettre un trap SNMP*
+
Permet de spécifier si les traps SNMP doivent être envoyés à l'hôte SNMP configuré globalement.

* *Exécuter le script*
+
Permet d'associer un script à l'alerte. Ce script est exécuté lorsqu'une alerte est générée.





[[command-buttons]]
== Boutons de commande

* *Sauvegarder*
+
Enregistre les modifications et ferme la boîte de dialogue.

* *Annuler*
+
Annule les modifications et ferme la boîte de dialogue.
