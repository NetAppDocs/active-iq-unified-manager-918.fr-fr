= Événements EMS ajoutés automatiquement à Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les événements ONTAP EMS suivants sont automatiquement ajoutés à Unified Manager. Ces événements sont générés lorsqu'ils sont déclenchés sur un cluster surveillé par Unified Manager.

Les événements EMS suivants sont disponibles lors de la surveillance des clusters exécutant le logiciel ONTAP 9.5 ou une version ultérieure :
