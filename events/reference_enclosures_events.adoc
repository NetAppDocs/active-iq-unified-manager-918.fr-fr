= Découvrez les événements liés aux enclosures dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les événements relatifs aux boîtiers de tiroir disque vous fournissent des informations sur l'état des boîtiers de tiroir disque dans votre centre de données afin que vous puissiez surveiller d'éventuels problèmes. Les événements sont regroupés par zone d'impact et incluent le nom de l'événement et du trap, le niveau d'impact, le type de source et la gravité.
