= Découvrez les événements liés aux inodes dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les événements d'inode fournissent des informations lorsque l'inode est plein ou presque plein, afin que vous puissiez surveiller d'éventuels problèmes. Les événements sont regroupés par zone d'impact et comprennent le nom de l'événement et du trap, le niveau d'impact, le type de source et la gravité.
