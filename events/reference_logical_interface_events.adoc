= Événements d'interface réseau dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les événements d'interface réseau fournissent des informations sur l'état de vos interfaces réseau (LIF), vous permettant ainsi de surveiller d'éventuels problèmes. Les événements sont regroupés par zone d'impact et comprennent le nom de l'événement et du piège, le niveau d'impact, le type de source et la gravité.
