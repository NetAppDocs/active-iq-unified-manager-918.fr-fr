= Découvrez les événements de la station de gestion dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les événements de la station de gestion vous fournissent des informations sur l'état du serveur sur lequel Unified Manager est installé, ce qui vous permet de surveiller d'éventuels problèmes. Les événements sont regroupés par zone d'impact et comprennent le nom de l'événement et du trap, le niveau d'impact, le type de source et la gravité.

[NOTE]
====
Ces deux derniers événements de performances étaient disponibles uniquement pour Unified Manager 7.2. Si l’un de ces événements existe à l’état « Nouveau » et que vous effectuez ensuite une mise à niveau vers une version plus récente du logiciel Unified Manager, les événements ne seront pas supprimés automatiquement. Vous devrez déplacer manuellement les événements vers l’état « Résolu ».
