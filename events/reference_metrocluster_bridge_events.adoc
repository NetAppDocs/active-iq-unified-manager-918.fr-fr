= Découvrez les événements Bridge MetroCluster dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les événements de pont MetroCluster vous fournissent des informations sur l'état des ponts afin que vous puissiez surveiller d'éventuels problèmes dans une configuration MetroCluster over FC. Les événements sont regroupés par zone d'impact et comprennent le nom de l'événement et de l'interruption, le niveau d'impact, le type de source et la gravité.
