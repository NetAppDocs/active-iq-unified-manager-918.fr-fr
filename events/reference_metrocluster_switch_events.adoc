= Découvrez les événements de commutation MetroCluster dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les événements de commutateur MetroCluster pour les configurations MetroCluster over FC vous fournissent des informations sur l'état des commutateurs MetroCluster afin que vous puissiez surveiller les problèmes potentiels. Les événements sont regroupés par zone d'impact et incluent le nom de l'événement et du trap, le niveau d'impact, le type de source et la gravité.
