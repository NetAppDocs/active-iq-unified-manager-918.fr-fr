= Découvrez les événements Qtree dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les événements qtree vous fournissent des informations sur la capacité du qtree ainsi que sur les limites des fichiers et des disques, ce qui vous permet de surveiller d’éventuels problèmes. Les événements sont regroupés par zone d’impact et incluent le nom de l’événement et du trap, le niveau d’impact, le type de source et la gravité.
