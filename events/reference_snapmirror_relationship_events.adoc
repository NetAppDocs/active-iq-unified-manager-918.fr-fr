= Découvrez les événements de relation SnapMirror dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les événements de relation SnapMirror vous fournissent des informations sur l'état de vos relations SnapMirror asynchrones et synchrones afin que vous puissiez surveiller les problèmes potentiels. Les événements de relation SnapMirror asynchrones sont générés pour les Storage VMs et les volumes, mais les événements de relation SnapMirror synchrones sont générés uniquement pour les relations de volumes. Aucun événement n'est généré pour les volumes constitutifs qui font partie des relations de reprise après sinistre de Storage VM. Les événements sont regroupés par zone d'impact et incluent le nom de l'événement et du trap, le niveau d'impact, le type de source et la gravité.



[[impact-area-protection]]
== Zone d'impact : protection

Un astérisque (*) identifie les événements EMS qui ont été convertis en événements Unified Manager.

[NOTE]
====
Les événements de relation SnapMirror sont générés pour les VM de stockage protégées par la reprise après sinistre des VM de stockage, mais pas pour les relations d’objets constitutifs.
