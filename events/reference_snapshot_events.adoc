= Découvrez les événements Snapshot dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les événements Snapshot fournissent des informations sur l'état des snapshots, ce qui vous permet de les surveiller afin de détecter d'éventuels problèmes. Les événements sont regroupés par zone d'impact et comprennent le nom de l'événement, le nom du trap, le niveau d'impact, le type de source et la gravité.
