= Découvrez les événements liés aux paramètres de basculement du stockage dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les événements liés aux paramètres de basculement du stockage (SFO) vous informent de l'état de votre basculement (désactivé ou non configuré) afin de vous permettre de détecter d'éventuels problèmes. Les événements sont regroupés par zone d'impact et comprennent le nom de l'événement et du piège, le niveau d'impact, le type de source et la gravité.
