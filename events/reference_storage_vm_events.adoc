= Découvrez les événements liés aux machines virtuelles de stockage dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les événements de Storage VM (storage virtual machine, également appelée SVM) vous fournissent des informations sur l’état de vos Storage VM (SVM) afin que vous puissiez surveiller d’éventuels problèmes. Les événements sont regroupés par zone d’impact et incluent le nom de l’événement et du trap, le niveau d’impact, le type de source et la gravité.

Un astérisque (*) identifie les événements EMS qui ont été convertis en événements Unified Manager.
