= Découvrez les événements liés aux quotas d'utilisateurs et de quota au groupe dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les événements de quota utilisateur et de quota au groupe vous fournissent des informations sur la capacité du quota utilisateur et du quota au groupe, ainsi que sur les limites de fichiers et de disques, afin de vous permettre de détecter d'éventuels problèmes. Les événements sont regroupés par zone d'impact et comprennent le nom de l'événement et du piège, le niveau d'impact, le type de source et la gravité.
