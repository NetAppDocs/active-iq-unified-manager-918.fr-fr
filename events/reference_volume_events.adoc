= Découvrez les événements de volume dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les événements de volume fournissent des informations sur l'état des volumes, ce qui vous permet de surveiller d'éventuels problèmes. Ces événements sont regroupés par zone d'impact et comprennent le nom de l'événement, le nom du piège, le niveau d'impact, le type de source et la gravité.

Un astérisque (*) identifie les événements EMS qui ont été convertis en événements Unified Manager.
