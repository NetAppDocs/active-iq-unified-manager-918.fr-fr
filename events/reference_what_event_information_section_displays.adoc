= Découvrez la section Informations sur l'événement dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous utilisez la section Informations sur l'événement sur la page Détails de l'événement pour consulter les détails concernant un événement sélectionné, tels que la gravité de l'événement, son niveau d'impact, sa zone d'impact et sa source.

Les champs qui ne s’appliquent pas au type d’événement sont masqués. Vous pouvez consulter les détails suivants de l'événement :

* *Heure de déclenchement de l'événement*
+
L'heure à laquelle l'événement a été généré.

* *État*
+
État de l'événement : Nouveau, acquitté, résolu ou obsolète.

* *Cause obsolète*
+
Les actions qui ont rendu l'événement obsolète, par exemple, le problème a été résolu.

* *Durée de l'événement*
+
Pour les événements actifs (nouveaux et reconnus), il s'agit du délai entre leur détection et leur dernière analyse. Pour les événements obsolètes, il s'agit du délai entre leur détection et leur résolution.

+
Ce champ s'affiche pour tous les événements de performance, et pour les autres types d'événements uniquement après leur résolution ou leur obsolescence.

* *Vu pour la dernière fois*
+
La date et l’heure auxquelles l’événement a été vu pour la dernière fois comme étant actif.

+
Pour les événements de performance, cette valeur peut être plus récente que l'heure de déclenchement de l'événement, car ce champ est mis à jour après chaque nouvelle collecte de données de performance tant que l'événement est actif. Pour les autres types d'événements, lorsqu'ils sont à l'état « Nouveau » ou « Accusé de réception », ce contenu n'est pas mis à jour et le champ est donc masqué.

* *Gravité*
+
La gravité de l'événement : Critique (image:../media/sev_critical_um60.png[""]), Erreur (image:../media/sev_error_um60.png[""]), Avertissement (image:../media/sev_warning_um60.png[""]) et Information (image:../media/sev_information_um60.gif[""]).

* *Niveau d'impact*
+
Niveau d'impact de l'événement : Incident, Risque, Événement ou Mise à niveau.

* *Zone d'impact*
+
Le domaine d'impact de l'événement : disponibilité, capacité, performance, protection, configuration ou sécurité.

* *Source*
+
Le nom de l'objet sur lequel l'événement s'est produit.

+
Lorsque vous consultez les détails d'un événement de stratégie QoS partagée, jusqu'à trois des objets workload qui consomment le plus d'IOPS ou de MBps sont répertoriés dans ce champ.

+
Vous pouvez cliquer sur le lien du nom de la source pour afficher la page de détails sur l'état ou les performances de cet objet.

* *Annotations de la source*
+
Affiche le nom et la valeur de l'annotation pour l'objet auquel l'événement est associé.

+
Ce champ s'affiche uniquement pour les événements liés à l'état de santé des clusters, des SVM et des volumes.

* *Groupes sources*
+
Affiche les noms de tous les groupes auxquels appartient l'objet concerné.

+
Ce champ s'affiche uniquement pour les événements liés à l'état de santé des clusters, des SVM et des volumes.

* *Type de source*
+
Le type d'objet (par exemple, SVM, Volume ou Qtree) auquel l'événement est associé.

* *Sur le cluster*
+
Le nom du cluster sur lequel l'événement s'est produit.

+
Vous pouvez cliquer sur le lien du nom du cluster pour afficher la page de détails sur l'état ou les performances de ce cluster.

* *Nombre d'objets affectés*
+
Le nombre d'objets affectés par l'événement.

+
Vous pouvez cliquer sur le lien de l'objet pour afficher la page d'inventaire contenant les objets actuellement affectés par cet événement.

+
Ce champ s'affiche uniquement pour les événements de performance.

* *Volumes concernés*
+
Le nombre de volumes concernés par cet événement.

+
Ce champ s'affiche uniquement pour les événements de performance sur les nœuds ou les agrégats.

* *Politique déclenchée*
+
Le nom de la politique de seuil qui a déclenché l'événement.

+
Vous pouvez survoler le nom de la stratégie avec le curseur pour afficher les détails de la stratégie de seuil. Pour les stratégies QoS adaptatives, la stratégie définie, la taille des blocs et le type d'allocation (espace alloué ou espace utilisé) sont également affichés.

+
Ce champ s'affiche uniquement pour les événements de performance.

* *Identifiant de la règle*
+
Pour les événements de la plateforme Active IQ, il s'agit du numéro de la règle qui a été déclenchée pour générer l'événement.

* *Reconnu par*
+
Le nom de la personne qui a pris acte de l'événement et l'heure à laquelle l'événement a été confirmé.

* *Résolu par*
+
Le nom de la personne qui a résolu l'événement et l'heure à laquelle l'événement a été résolu.

* *Attribué à*
+
Le nom de la personne chargée de travailler sur l'événement.

* *Paramètres d'alerte*
+
Les informations suivantes concernant les alertes sont affichées :

+
** S'il n'existe aucune alerte associée à l'événement sélectionné, un lien *Ajouter une alerte* s'affiche.
+
Vous pouvez ouvrir la boîte de dialogue Ajouter une alerte en cliquant sur le lien.

** Si une alte est associée à l'événement sélectionné, son nom s'affiche.
+
Vous pouvez ouvrir la boîte de dialogue Modifier l'alerte en cliquant sur le lien.

** S'il existe plusieurs alertes associées à l'événement sélectionné, le nombre d'alertes s'affiche.
+
Vous pouvez ouvrir la page de configuration des alertes en cliquant sur le lien pour consulter plus de détails sur ces alertes.



+
Les alertes désactivées ne sont pas affichées.

* *Dernière notification envoyée*
+
Date et heure d'envoi de la dernière notification d'alerte.

* *Envoyer avant*
+
Le mécanisme utilisé pour envoyer la notification d'alerte : courriel ou trap SNMP.

* *Exécution précédente du script*
+
Le nom du script qui a été exécuté lors de la génération de l'alerte.
