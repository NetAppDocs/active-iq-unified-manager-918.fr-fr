= Résolvez les problèmes à l'aide de la correction automatique dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager peut diagnostiquer certains événements en détail et proposer une solution unique grâce au bouton *Fix It*. Le cas échéant, ces solutions s'affichent dans le tableau de bord, sur la page de détails de l'événement et dans l'option « Analyse de la charge de travail » du menu de navigation de gauche.

La plupart des événements ont plusieurs résolutions possibles, affichées sur la page de détails de l'événement, afin que vous puissiez mettre en œuvre la meilleure solution à l'aide de ONTAP System Manager ou de l'interface de ligne de commande ONTAP. Une action *Fix It* est disponible lorsque Unified Manager a déterminé qu'il existe une seule résolution pour corriger le problème et qu'elle peut être mise en œuvre à l'aide d'une commande de l'interface de ligne de commande ONTAP.

.Étapes
. Pour afficher les événements qui peuvent être corrigés depuis *Dashboard*, cliquez sur *Dashboard*.
+
image::../media/management_actions.png[Capture d'écran de l'interface utilisateur montrant comment consulter et corriger les événements depuis le tableau de bord.]

. Pour résoudre l’un des problèmes que Unified Manager peut corriger, cliquez sur le bouton *Fix It*. Pour corriger un problème qui existe sur plusieurs objets, cliquez sur le bouton *Fix All*.


Pour plus d'informations sur les problèmes pouvant être résolus par une correction automatique, consultez link:..//storage-mgmt/reference_what_ontap_issues_can_unified_manager_fix.html["Quels problèmes Unified Manager peut-il résoudre"].
