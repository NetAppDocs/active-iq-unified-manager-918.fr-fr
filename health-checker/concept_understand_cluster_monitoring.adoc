= Comprendre la surveillance des clusters dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez ajouter des clusters à la base de données Unified Manager pour surveiller leur disponibilité, leur capacité et d'autres détails, tels que l'utilisation du processeur, les statistiques d'interface, l'espace disque libre, l'utilisation des qtree et l'environnement du châssis.

Des événements sont générés en cas d'anomalie ou lorsqu'un seuil prédéfini est dépassé. Si cette option est configurée, Unified Manager envoie une notification à un destinataire spécifié lorsqu'un événement déclenche une alerte.
