= Comprendre les catégories de conformité des clusters dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ce tableau décrit les paramètres de conformité de sécurité du cluster évalués par Unified Manager, la recommandation de NetApp et indique si le paramètre influe sur la détermination globale de la conformité ou non-conformité du cluster.

La présence de SVM non conformes au sein d'un cluster affectera le niveau de conformité de ce dernier. Il peut donc être nécessaire, dans certains cas, de corriger une faille de sécurité liée à une SVM avant que la sécurité du cluster ne soit considérée comme conforme.

Notez que tous les paramètres répertoriés ci-dessous n'apparaissent pas pour toutes les installations. Par exemple, si vous n'avez aucun cluster apparié, ou si vous avez désactivé AutoSupport sur un cluster, vous ne verrez pas les éléments « Appairage de clusters » ou « Transport HTTPS de AutoSupport » dans la page de l'interface utilisateur.

[cols="4*"]
|===
| Paramètre | Description | Recommandation | Affecte la conformité du cluster 


 a| 
FIPS global
 a| 
Indique si le mode de conformité Global FIPS (Federal Information Processing Standard) 140-2 est activé ou désactivé. Lorsque FIPS est activé, TLSv1 et SSLv3 sont désactivés, et seuls TLSv1.1 et TLSv1.2 sont autorisés.
 a| 
Activé
 a| 
Oui



 a| 
Telnet
 a| 
Indique si l'accès Telnet au système est activé ou désactivé. NetApp recommande Secure Shell (SSH) pour un accès distant sécurisé.
 a| 
Désactivées
 a| 
Oui



 a| 
Paramètres SSH non sécurisés
 a| 
Indique si SSH utilise des chiffrements non sécurisés, par exemple des chiffrements commençant par *cbc.
 a| 
Non
 a| 
Oui



 a| 
Bannière de connexion
 a| 
Indique si la bannière de connexion est activée ou désactivée pour les utilisateurs accédant au système.
 a| 
Activé
 a| 
Oui



 a| 
Interconnexion de clusters
 a| 
Indique si la communication entre les clusters appariés est chiffrée ou non chiffrée. Le chiffrement doit être configuré sur les clusters source et de destination pour que ce paramètre soit considéré comme conforme.
 a| 
Chiffré
 a| 
Oui



 a| 
Protocole de temps réseau
 a| 
Indique si le cluster possède un ou plusieurs serveurs NTP configurés. Pour une redondance et un service optimaux, NetApp recommande d'associer au moins trois serveurs NTP au cluster.
 a| 
configuré
 a| 
Oui



 a| 
OCSP
 a| 
À partir de la version 9.14.1, Active IQ Unified Manager fournit des informations d'état OCSP (Online Certificate Status Protocol) au niveau de la machine virtuelle de stockage (SVM, anciennement appelée Vserver). Cela signifie que la validation OCSP est appliquée à toutes les connexions SSL/TLS établies avec la SVM et garantit l'intégrité et la validité des certificats utilisés dans ces connexions.
 a| 
Activé
 a| 
Non



 a| 
Journalisation des audits à distance
 a| 
Indique si le transfert des journaux (Syslog) est chiffré ou non chiffré.
 a| 
Chiffré
 a| 
Oui



 a| 
Transport HTTPS AutoSupport
 a| 
Indique si HTTPS est utilisé comme protocole de transport par défaut pour l'envoi des messages AutoSupport au support NetApp.
 a| 
Activé
 a| 
Oui



 a| 
Utilisateur administrateur par défaut
 a| 
Indique si l'utilisateur administrateur par défaut (intégré) est activé ou désactivé. NetApp recommande de verrouiller (désactiver) tout compte intégré inutile.
 a| 
Désactivées
 a| 
Oui



 a| 
Utilisateurs SAML
 a| 
Indique si SAML est configuré. SAML vous permet de configurer l'authentification multifacteur (MFA) comme méthode de connexion pour l'authentification unique.
 a| 
Non
 a| 
Non



 a| 
Utilisateurs Active Directory
 a| 
Indique si Active Directory est configuré. Active Directory et LDAP sont les mécanismes d'authentification privilégiés pour les utilisateurs accédant aux clusters.
 a| 
Non
 a| 
Non



 a| 
Utilisateurs LDAP
 a| 
Indique si LDAP est configuré. Active Directory et LDAP sont les mécanismes d'authentification privilégiés pour les utilisateurs gérant des clusters par rapport aux utilisateurs locaux.
 a| 
Non
 a| 
Non



 a| 
Utilisateurs de certificats
 a| 
Indique si un utilisateur disposant d'un certificat est configuré pour se connecter au cluster.
 a| 
Non
 a| 
Non



 a| 
Utilisateurs locaux
 a| 
Indique si les utilisateurs locaux sont configurés pour se connecter au cluster.
 a| 
Non
 a| 
Non



 a| 
Shell à distance
 a| 
Indique si le protocole RSH est activé. Pour des raisons de sécurité, il est recommandé de désactiver RSH. L'utilisation de Secure Shell (SSH) est préférable pour un accès distant sécurisé.
 a| 
Désactivées
 a| 
Oui



 a| 
MD5 en cours d'utilisation
 a| 
Indique si les comptes utilisateurs ONTAP utilisent la fonction de hachage MD5 moins sécurisée. Il est recommandé de migrer les comptes utilisateurs utilisant le hachage MD5 vers une fonction de hachage cryptographique plus sécurisée, telle que SHA-512.
 a| 
Non
 a| 
Oui



 a| 
Type d'émetteur de certificat
 a| 
Indique le type de certificat numérique utilisé.
 a| 
Signé par CA
 a| 
Non
