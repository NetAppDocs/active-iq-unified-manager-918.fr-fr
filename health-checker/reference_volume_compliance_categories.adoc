= Comprendre les catégories de conformité des volumes dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ce tableau décrit les paramètres de chiffrement des volumes que Unified Manager évalue pour déterminer si les données de vos volumes sont suffisamment protégées contre l'accès par des utilisateurs non autorisés.

Notez que les paramètres de chiffrement du volume n'ont aucune incidence sur la conformité du cluster ou de la machine virtuelle de stockage.

[cols="2*"]
|===
| Paramètre | Description 


 a| 
Chiffré par logiciel
 a| 
Affiche le nombre de volumes protégés à l’aide des solutions de chiffrement logiciel NetApp Volume Encryption (NVE) ou NetApp Aggregate Encryption (NAE).



 a| 
Chiffrement matériel
 a| 
Affiche le nombre de volumes protégés à l’aide du chiffrement matériel NetApp Storage Encryption (NSE).



 a| 
Logiciels et matériels chiffrés
 a| 
Affiche le nombre de volumes protégés à la fois par le chiffrement logiciel et matériel.



 a| 
Non chiffré
 a| 
Affiche le nombre de volumes non chiffrés.

|===
