= Ajoutez des alertes pour les événements de sécurité dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez configurer des alertes pour des événements de sécurité individuels, comme pour tout autre événement reçu par Unified Manager. De plus, si vous souhaitez traiter tous les événements de sécurité de la même manière et envoyer un e-mail à la même personne, vous pouvez créer une alerte unique qui vous notifiera lorsque des événements de sécurité sont déclenchés.

.Avant de commencer
Vous devez disposer du rôle Application Administrator ou Storage Administrator.

L'exemple ci-dessous montre comment créer une alerte pour l'événement de sécurité « `Telnet Protocol Enabled` ». Cela enverra une alerte si l'accès Telnet est configuré pour l'administration à distance du cluster. Vous pouvez utiliser cette même méthode pour créer des alertes pour tous les événements de sécurité.

.Étapes
. Dans le volet de navigation de gauche, cliquez sur *Gestion du stockage* > *Configuration des alertes*.
. Sur la page *Configuration des alertes*, cliquez sur *Ajouter*.
. Dans la boîte de dialogue *Ajouter une alerte*, cliquez sur *Nom*, puis saisissez un nom et une description pour l'alerte.
. Cliquez sur *Ressources* et sélectionnez le ou les clusters sur lesquels vous souhaitez activer cette alerte.
. Cliquez sur *Événements* et effectuez les actions suivantes :
+
.. Dans la liste Gravité de l'événement, sélectionnez *Avertissement*.
.. Dans la liste des événements correspondants, sélectionnez *Protocole Telnet activé*.


. Cliquez sur *Actions*, puis sélectionnez le nom de l’utilisateur qui recevra l’e-mail d’alerte dans le champ *Alerter ces utilisateurs*.
. Configurez les autres options sur cette page concernant la fréquence des notifications, l'émission de traps SNMP et l'exécution d'un script.
. Cliquez sur *Enregistrer*.
