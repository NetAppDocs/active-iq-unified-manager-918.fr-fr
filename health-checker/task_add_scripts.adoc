= Ajouter des scripts dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez ajouter des scripts dans Unified Manager et associer les scripts à des alertes. Ces scripts s'exécutent automatiquement lorsqu'une alerte est générée et vous permettent d'obtenir des informations sur les objets de stockage pour lesquels l'événement est généré.

.Avant de commencer
* Vous devez avoir créé et enregistré les scripts que vous souhaitez ajouter au serveur Unified Manager.
* Les formats de fichiers pris en charge pour les scripts sont Perl, Shell, PowerShell, Python et `.bat` fichiers.
+
[cols="2*"]
|===
| Plateforme sur laquelle Unified Manager est installé | Langues prises en charge 


 a| 
VMware
 a| 
Scripts Perl et Shell



 a| 
Linux
 a| 
Scripts Perl, Python et Shell



 a| 
Windows
 a| 
PowerShell, Perl, Python et scripts .bat

|===
+
** Pour les scripts Perl, Perl doit être installé sur le serveur Unified Manager. Sur les installations VMware, Perl 5 est installé par défaut et les scripts ne prendront en charge que les fonctionnalités de Perl 5. Si Perl a été installé après Unified Manager, vous devez redémarrer le serveur Unified Manager.
** Pour les scripts PowerShell, la stratégie d’exécution PowerShell appropriée doit être définie sur le serveur Windows afin que les scripts puissent être exécutés.


+
[NOTE]
====
Si votre script crée des fichiers journaux pour suivre la progression du script d'alerte, vous devez vous assurer que ces fichiers journaux ne sont créés nulle part dans le dossier d'installation d'Unified Manager.

====
* Vous devez disposer du rôle Application Administrator ou Storage Administrator.


Vous pouvez télécharger des scripts personnalisés et recueillir des détails sur l'événement lié à l'alerte.

[NOTE]
====
Si cette fonctionnalité n'apparaît pas dans l'interface utilisateur, c'est parce qu'elle a été désactivée par votre administrateur. Si nécessaire, vous pouvez activer cette fonctionnalité dans *Gestion du stockage* > *Paramètres des fonctionnalités*.

====
.Étapes
. Dans le volet de navigation de gauche, cliquez sur *Gestion du stockage* > *Scripts*.
. Sur la page *Scripts*, cliquez sur *Ajouter*.
. Dans la boîte de dialogue *Ajouter un script*, cliquez sur *Parcourir* pour sélectionner votre fichier de script.
. Saisissez une description pour le script que vous sélectionnez.
. Cliquez sur *Add*.
