= Calculer l'espace récupérable pour les copies Snapshot dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez calculer la quantité d'espace disque qui peut être récupérée si une ou plusieurs copies Snapshot sont supprimées.

.Avant de commencer
* Vous devez avoir le rôle Operator, Application Administrator ou Storage Administrator.
* Le volume doit être en ligne.
* Le volume doit être un volume FlexVol ; cette fonctionnalité n'est pas prise en charge avec les volumes FlexGroup.


.Étapes
. Dans le volet de navigation de gauche, cliquez sur *Stockage* > *Volumes*.
. Dans la vue *Santé : Tous les volumes*, sélectionnez le volume contenant les copies Snapshot que vous souhaitez consulter.
+
La liste des copies Snapshot s'affiche.

. Sur la page de détails *Volume / Santé*, cliquez sur l'onglet *Capacité*.
. Dans le volet *Détails* de l’onglet *Capacité*, dans la section Autres détails, cliquez sur le lien en regard de *Copies instantanées*.
+
Le nombre de copies Snapshot est un lien qui affiche la liste des copies Snapshot.

. Dans la vue *Snapshot Copies*, sélectionnez les copies Snapshot pour lesquelles vous souhaitez calculer l'espace récupérable.
. Cliquez sur *Calculate*.
+
L'espace récupérable (en pourcentage, et en Ko, Mo, Go, etc.) sur le volume est affiché.

. Pour recalculer l'espace récupérable, sélectionnez les copies Snapshot requises et cliquez sur *Recalculer*.
