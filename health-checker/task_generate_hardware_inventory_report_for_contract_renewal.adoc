= Générez un rapport d'inventaire matériel pour le renouvellement du contrat dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez générer un rapport contenant une liste complète des informations sur le cluster et les nœuds, telles que les numéros de modèle et les numéros de série du matériel, les types et le nombre de disques, les licences installées, et bien plus encore. Ce rapport est utile pour le renouvellement des contrats au sein de sites sécurisés (« `dark` ») qui ne sont pas connectés à la plateforme NetAppActive IQ.

.Avant de commencer
Vous devez avoir le rôle Operator, Application Administrator ou Storage Administrator.

.Étapes
. Dans le volet de navigation de gauche, cliquez sur *Stockage* > *Nœuds*.
. Accédez à la vue *Santé : Tous les nœuds* ou à la vue *Performances : Tous les nœuds*.
. Sélectionnez *Rapports* > *** > **Rapport d'inventaire du matériel*.
+
Le rapport d'inventaire du matériel est téléchargé sous la forme d'un fichier .csv contenant toutes les informations à la date du jour.

. Veuillez transmettre ces informations à votre contact du support NetApp pour le renouvellement de votre contrat.
