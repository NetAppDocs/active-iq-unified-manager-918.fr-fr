= Envoyez un dossier de support via l'interface web et la console de maintenance dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous devez envoyer un dossier de support lorsque le problème que vous rencontrez nécessite un diagnostic et un dépannage plus détaillés que ce qu’un message AutoSupport fournit. Vous pouvez envoyer un dossier de support au support technique à l’aide de l’interface Web Ui de Unified Manager et de la console de maintenance.

Unified Manager stocke au maximum deux ensembles de support complets et trois ensembles de support allégés à la fois.
