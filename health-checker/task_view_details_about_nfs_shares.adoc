= Consultez les détails relatifs aux partages NFS dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez afficher des détails sur tous les partages NFS, tels que leur état, le chemin associé au volume (volumes FlexGroup ou volumes FlexVol®), les niveaux d'accès des clients aux partages NFS et les règles d'export définies pour les volumes exportés. Utilisez la vue Santé : tous les partages NFS pour afficher tous les partages NFS sur l'ensemble des clusters surveillés, et utilisez la page Détails de la VM de stockage / Santé pour afficher tous les partages NFS sur une machine virtuelle de stockage (SVM) spécifique.

.Avant de commencer
* La licence NFS doit être activée sur le cluster.
* Les interfaces réseau desservant les partages NFS doivent être configurées.
* Vous devez avoir le rôle Operator, Application Administrator ou Storage Administrator.


.Étape
. Dans le volet de navigation de gauche, suivez les étapes ci-dessous selon que vous souhaitez afficher tous les partages NFS ou uniquement les partages NFS d'une SVM particulière.
+
[cols="2*"]
|===
| À... | Suivez ces étapes... 


 a| 
Afficher tous les partages NFS
 a| 
Cliquez sur *Stockage* > *Partages NFS*



 a| 
Afficher les partages NFS pour une seule SVM
 a| 
.. Cliquez sur *Stockage* > *Machines virtuelles de stockage*
.. Cliquez sur le SVM pour lequel vous souhaitez afficher les détails des partages NFS.
.. Dans la page Détails de la machine virtuelle de stockage / État, cliquez sur l'onglet *Partages NFS*.


|===
