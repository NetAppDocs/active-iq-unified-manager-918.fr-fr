= Mettez à niveau les produits tiers après avoir installé Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez mettre à niveau des produits tiers, tels que JRE, même si Unified Manager est déjà installé sur les systèmes Linux.

Les entreprises qui développent ces produits tiers signalent régulièrement les failles de sécurité. Vous pouvez effectuer la mise à niveau vers des versions plus récentes de ce logiciel à votre convenance.
