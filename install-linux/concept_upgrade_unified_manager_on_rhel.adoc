= Mise à niveau d'Active IQ Unified Manager sur Red Hat Enterprise Linux
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez mettre à niveau Unified Manager lorsqu'une nouvelle version est disponible.

Les correctifs du logiciel Unified Manager, lorsqu'ils sont fournis par NetApp, sont installés selon la même procédure que les nouvelles versions.

Si Unified Manager est associé à une instance de OnCommand Workflow Automation et que de nouvelles versions logicielles sont disponibles pour les deux produits, vous devez déconnecter les deux produits, puis configurer une nouvelle connexion Workflow Automation après avoir effectué les mises à niveau. Si vous effectuez une mise à niveau d'un seul des produits, vous devez alors vous connecter à Workflow Automation après la mise à niveau et vérifier qu'il continue à acquérir des données depuis Unified Manager.
