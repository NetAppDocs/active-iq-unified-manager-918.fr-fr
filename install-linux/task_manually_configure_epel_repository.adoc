= Configurer le référentiel EPEL pour Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Si le système sur lequel vous installez Unified Manager n'a pas accès au dépôt Extra Packages for Enterprise Linux (EPEL), vous devez télécharger et configurer manuellement le dépôt pour une installation réussie.

Le dépôt EPEL donne accès aux utilitaires tiers requis qui doivent être installés sur votre système. Vous utilisez le dépôt EPEL pour installer Unified Manager sur un système Red Hat Enterprise Linux.

.Étapes
. Téléchargez le dépôt EPEL pour votre installation. Pour la version 8, téléchargez-le depuis :
+
`+wget https://dl.fedoraproject.org/pub/epel/epel-release-latest-8.noarch.rpm+`

+
Pour la version 9, téléchargez-la depuis :

+
`wget https://dl.fedoraproject.org/pub/epel/epel-release-latest-9.noarch.rpm`

. Configurer le référentiel EPEL:
+
`yum install epel-release-latest-<version>.noarch.rpm`



Pour les systèmes Red Hat Enterprise Linux 8, si vous disposez de dépôts internes avec des paquets RPM modulaires, par exemple, `_javapackages-filesystem-<version>.module.rpm_`, assurez-vous que les métadonnées des paquets modulaires sont également disponibles dans le même dépôt.
