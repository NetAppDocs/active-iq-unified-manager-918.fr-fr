= Redémarrer Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Il se peut que vous deviez redémarrer Unified Manager après avoir effectué des modifications de configuration.

.Avant de commencer
Vous devez disposer d'un accès utilisateur root au serveur Red Hat Enterprise Linux sur lequel Unified Manager est installé.

.Étapes
. Connectez-vous en tant qu'utilisateur root au serveur sur lequel vous souhaitez redémarrer le service Unified Manager.
. Arrêtez le service Unified Manager et le service MySQL associé dans cet ordre :
+
`systemctl stop ocieau`

+
`systemctl stop ocie`

+
`systemctl stop mysqld`

. Démarrez les services MySQL et Unified Manager dans cet ordre :
+
`systemctl start mysqld`

+
`systemctl start ocie`

+
`systemctl start ocieau`



[NOTE]
====
`mysqld` est un programme démon nécessaire pour démarrer et arrêter le serveur MySQL.

====
