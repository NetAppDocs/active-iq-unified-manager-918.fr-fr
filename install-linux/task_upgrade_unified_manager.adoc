= Mise à niveau d'Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez mettre à niveau Unified Manager 9.14 ou 9.16 vers la version 9.18 en téléchargeant et en exécutant le fichier d'installation sur la plateforme Linux.

.Avant de commencer
* Le système sur lequel vous mettez à niveau Unified Manager doit respecter les exigences système et logicielles.
+
Voir link:concept_virtual_infrastructure_or_hardware_system_requirements.html["Configuration matérielle requise du système"].

+
Voir link:reference_red_hat_software_and_installation_requirements.html["Logiciels Linux et exigences d'installation"].

* Vous devez disposer d'un abonnement au gestionnaire d'abonnements Red Hat Enterprise Linux.
* Vous devez installer OpenJDK ou le mettre à niveau vers la version correcte avant de mettre à niveau Unified Manager.
+
Voir link:task_upgrade_openjdk_on_linux_ocum.html["Mise à jour de JRE sous Linux"].

* Vous devez installer ou mettre à niveau 7-zip vers la version appropriée avant de mettre à niveau Unified Manager. Voir link:task_configure_7zip_package.html["Configurer le package logiciel 7-zip"].
* Pour éviter toute perte de données, vous devez avoir créé une sauvegarde de la base de données Unified Manager au cas où un problème surviendrait pendant la mise à niveau. NetApp recommande de déplacer le fichier de sauvegarde du `/opt/netapp/data` répertoire vers un emplacement externe.
* Lors de la mise à niveau, il vous sera peut-être demandé de confirmer si vous souhaitez conserver les paramètres par défaut précédents pour la conservation des données de performance pendant 13 mois ou les modifier pour une durée de 6 mois. Après confirmation, l'historique des données de performance est supprimé au bout de 6 mois.
* Vous devez avoir terminé toutes les opérations en cours, car Unified Manager n'est pas disponible pendant le processus de mise à niveau.
* MySQL Community Edition est automatiquement mis à niveau lors de la mise à niveau de Unified Manager. Si la version de MySQL installée sur votre système est antérieure à 8.4.10, le processus de mise à niveau de Unified Manager met automatiquement MySQL à niveau vers 8.4.10.


.Étapes
. Connectez-vous au serveur Red Hat Enterprise Linux cible.
. Téléchargez le bundle Unified Manager sur le serveur.
+
Voir link:task_download_unified_manager.html["Téléchargement d'Unified Manager pour Linux"].

. Accédez au répertoire cible et décompressez le package Unified Manager :
+
`unzip ActiveIQUnifiedManager-<version>.zip`

+
Les modules RPM requis pour Unified Manager sont décompressés dans le répertoire cible.

. Vérifiez que le module suivant est disponible dans le répertoire :
+
`ls *.rpm`

+
`netapp-um<version>.x86_64.rpm`

. Exécutez le script de pré-installation pour vous assurer qu'aucun paramètre de configuration système ni aucun logiciel installé ne risque d'entrer en conflit avec la mise à niveau :
+
`sudo ./pre_install_check.sh`

+
Le script de pré-installation vérifie que le système dispose d'un abonnement Red Hat Enterprise Linux valide et qu'il a accès aux dépôts logiciels requis. Si le script détecte des problèmes, vous devez les résoudre et poursuivre la mise à niveau.

+
Si des paquets manquants sont détectés, suivez les étapes mentionnées dans link:../install-linux/task_upgrade_unified_manager.html#additional-steps-to-perform-for-missing-packages["Étapes supplémentaires à effectuer pour les paquets manquants"]. S'il n'y a pas de paquets manquants, poursuivez avec les étapes suivantes.

. Mettez à niveau Unified Manager à l'aide du script suivant :
+
`upgrade.sh`

+
Ce script exécute automatiquement les modules RPM, en mettant à niveau les logiciels de prise en charge nécessaires et les modules Unified Manager qui s’exécutent sur ceux-ci. De plus, le script de mise à niveau vérifie s’il existe des paramètres de configuration système ou des logiciels installés susceptibles d’entrer en conflit avec la mise à niveau. Si le script détecte des problèmes, vous devez les résoudre avant de mettre à niveau Unified Manager. Si vous avez précédemment installé des packages, tels que _net-snmp_, avant de mettre à niveau Unified Manager, la dépendance MySQL peut désinstaller le package pendant la mise à niveau. Vous devez réinstaller manuellement le package pour continuer à l’utiliser.

. Une fois la mise à niveau terminée, faites défiler les messages en sens inverse jusqu'à ce que vous voyiez le message affichant une adresse IP ou une URL pour l'interface utilisateur Web de Unified Manager, le nom d'utilisateur de maintenance (umadmin) et le mot de passe par défaut.
+
Le message est similaire au suivant :

+
[listing]
----
Active IQ Unified Manager upgraded successfully.
Use a web browser and one of the following URLs to access the Unified Manager GUI:

https://default_ip_address/    (if using IPv4)
https://[default_ip_address]/  (if using IPv6)
https://fully_qualified_domain_name/
----


Saisissez l'adresse IP ou l'URL spécifiée dans une nouvelle fenêtre d'un navigateur Web pris en charge pour ouvrir l'interface utilisateur Web de Unified Manager, puis connectez-vous en utilisant le même nom d'utilisateur de maintenance (umadmin) et le même mot de passe que vous avez définis précédemment.

== Étapes supplémentaires à effectuer pour les paquets manquants

Si des paquets manquants sont détectés sur votre site lors de la mise à niveau, ou si votre système n'est pas connecté à Internet, ou si vous n'utilisez pas les dépôts Red Hat Enterprise Linux, suivez les étapes suivantes pour déterminer si des paquets requis vous manquent et téléchargez ces paquets.


NOTE: Ces étapes doivent être effectuées après l’étape _5_ de la procédure principale. Cette procédure met à niveau Unified Manager et vous n’avez pas besoin d’exécuter d’étapes supplémentaires pour la mise à niveau.

. Consultez la liste des paquets disponibles et indisponibles :
+
`yum install netapp-um<version>.x86_64.rpm --assumeno`

+
Les éléments de la section « `Installing:` » correspondent aux paquets disponibles dans le répertoire actuel, et les éléments de la section « `Installing for dependencies:` » correspondent aux paquets manquants sur votre système.

. Sur un autre système disposant d'un accès à Internet, exécutez la commande suivante pour télécharger les paquets manquants.
+
`yum install package_name --downloadonly --downloaddir=.`

+
Les paquets sont téléchargés dans le répertoire spécifié comme `--downloaddir=`.

+
Étant donné que le module complémentaire « `yum-plugin-downloadonly` » n'est pas toujours activé sur les systèmes Red Hat Enterprise Linux, vous devrez peut-être activer la fonctionnalité permettant de télécharger un paquet sans l'installer :

+
`yum install yum-plugin-downloadonly`

. Copiez les packages téléchargés dans le répertoire où vous avez décompressé le bundle Unified Manager sur le système d'installation.
. Accédez à ce répertoire et exécutez la commande suivante pour installer les paquets manquants, ainsi que leurs dépendances.
+
`yum install *.rpm`

. Démarrez le serveur Unified Manager. Exécutez les commandes suivantes :
+
`systemctl start ocie`

+
`systemctl start ocieau`



Cette procédure termine le processus de mise à niveau d'Unified Manager. Saisissez l'adresse IP ou l'URL indiquée dans une nouvelle fenêtre d'un navigateur web compatible pour démarrer l'interface utilisateur web d'Unified Manager, puis connectez-vous à l'aide du même nom d'utilisateur de maintenance (umadmin) et du mot de passe que vous avez définis précédemment.
