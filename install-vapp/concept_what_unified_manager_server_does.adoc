= Découvrez ce que fait le serveur Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
L'infrastructure serveur d'Unified Manager se compose d'une unité de collecte de données, d'une base de données et d'un serveur applicatif. Elle fournit des services d'infrastructure tels que la découverte, la surveillance, le contrôle d'accès basé sur les rôles (RBAC), l'audit et la journalisation.

Unified Manager collecte les informations du cluster, stocke les données dans la base de données et les analyse pour détecter d'éventuels problèmes au niveau du cluster.
