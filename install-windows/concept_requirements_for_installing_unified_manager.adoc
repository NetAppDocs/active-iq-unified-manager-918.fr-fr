= Assurez-vous que le serveur répond aux exigences d'installation d'Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Avant de commencer le processus d'installation, assurez-vous que le serveur sur lequel vous souhaitez installer Unified Manager répond aux exigences spécifiques en matière de logiciels, de matériel, de processeur et de mémoire.

NetApp ne prend pas en charge toute modification du code de l'application Unified Manager. Si vous devez appliquer des mesures de sécurité au serveur Unified Manager, vous devez effectuer ces modifications au niveau du système d'exploitation sur lequel Unified Manager est installé.

Pour plus de détails sur l'application des mesures de sécurité au serveur Unified Manager, consultez l'article de la base de connaissances.
