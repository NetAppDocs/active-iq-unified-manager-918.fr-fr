= Comprendre les exigences en matière d'infrastructure virtuelle et de matériel pour Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
L'installation d'Unified Manager sur une infrastructure virtuelle ou un système physique doit respecter les exigences minimales en matière de mémoire, de processeur et d'espace disque.

Le tableau suivant présente les valeurs recommandées pour la mémoire, le processeur et l'espace disque. Ces valeurs ont été validées afin que Unified Manager offre des performances acceptables.

[cols="2*"]
|===
| Configuration matérielle | Paramètres recommandés 


 a| 
RAM
 a| 
12 Go



 a| 
Processeurs
 a| 
4 processeurs



 a| 
capacité en cycles CPU
 a| 
9572 MHz au total (exigence minimale 9572 MHz)



 a| 
Espace disque libre
 a| 
150 Go, dont la capacité est répartie comme suit :

* 100 Go d'espace disque pour le répertoire d'installation
* 50 Go d'espace disque pour le répertoire de données MySQL


|===
Unified Manager peut être installé sur des systèmes disposant de peu de mémoire, mais les 12 Go de RAM recommandés garantissent qu’une quantité de mémoire suffisante est disponible pour des performances optimales et permettent au système d’accueillir des clusters et des objets de stockage supplémentaires à mesure que votre configuration évolue. Vous ne devez définir aucune limite de mémoire sur la machine virtuelle sur laquelle Unified Manager est déployé et ne devez activer aucune fonctionnalité (par exemple, le ballooning) qui empêcherait le logiciel d’utiliser la mémoire allouée sur le système.

De plus, il existe une limite au nombre de nœuds qu'une seule instance d'Unified Manager peut surveiller avant que vous n'installiez une seconde instance d'Unified Manager. Pour connaître les limites de nœuds, les recommandations concernant le processeur et la mémoire, consultez  https://www.netapp.com/pdf.html?item=/media/13504-tr4621.pdf["le guide des bonnes pratiques de Unified Manager"^].

L’échange de pages mémoire a un impact négatif sur les performances du système et de l’application de gestion. La concurrence pour les ressources du processeur indisponibles en raison de l’utilisation globale de l’hôte peut dégrader les performances.



[[requirement-for-dedicated-use]]
== Exigence d'utilisation dédiée

Le système physique ou virtuel sur lequel vous installez Unified Manager doit être utilisé exclusivement pour Unified Manager et ne doit pas être partagé avec d'autres applications. Ces dernières peuvent consommer des ressources système et réduire considérablement les performances d'Unified Manager.



[[space-requirements-for-backups]]
== Besoins en espace pour les sauvegardes

Si vous prévoyez d'utiliser la fonction de sauvegarde et de restauration d'Unified Manager, allouez une capacité supplémentaire afin que le répertoire ou le disque « `data` » dispose de 150 Go d'espace. Une sauvegarde peut être écrite vers une destination locale ou une destination distante. La bonne pratique consiste à identifier un emplacement distant, externe au système hôte d'Unified Manager, disposant d'au moins 150 Go d'espace.



[[requirements-for-host-connectivity]]
== Exigences en matière de connectivité hôte

Le système physique ou le système virtuel sur lequel vous installez Unified Manager doit être configuré de telle sorte que vous puissiez `ping` résoudre correctement le nom de l'hôte à partir de l'hôte lui-même. En cas de configuration IPv6, vous devez vérifier que `ping6` la résolution du nom de l'hôte aboutit afin de garantir la réussite de l'installation d'Unified Manager.

Vous pouvez utiliser le nom de l'hôte (ou l'adresse IP de l'hôte) pour accéder à l'interface utilisateur web du produit. Si vous avez configuré une adresse IP statique pour votre réseau lors du déploiement, vous avez alors attribué un nom à l'hôte réseau. Si vous avez configuré le réseau à l'aide de DHCP, vous devez obtenir le nom de l'hôte auprès du DNS.

Si vous prévoyez d'autoriser les utilisateurs à accéder à Unified Manager en utilisant le nom court au lieu d'utiliser le nom de domaine complet (FQDN) ou l'adresse IP, votre configuration réseau doit résoudre ce nom court en un FQDN valide.
