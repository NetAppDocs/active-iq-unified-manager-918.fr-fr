= Désinstallez les produits tiers dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Après la mise à niveau d'Unified Manager, vous pouvez désinstaller les produits tiers, tels que Python ou Microsoft Visual C++ 2013. Cette opération est facultative.



[[uninstall-python]]
== Désinstaller Python

.Étapes
. Dans le *Panneau de configuration*, sélectionnez *Programmes* > *Programmes et fonctionnalités*.
. Sélectionnez Python dans la liste des programmes.
. Sélectionnez *Désinstaller ce programme*. Désinstallez toute version de Python à l'exception de 3.13.3. Assurez-vous de conserver la version 3.13.3 de Python.




[[uninstall-microsoft-visual-c-2013]]
== Désinstaller Microsoft Visual C++ 2013

.Étapes
. Dans le *Panneau de configuration*, sélectionnez *Programmes* > *Programmes et fonctionnalités*.
. Sélectionnez *Microsoft Visual C++ 2013* dans la liste des programmes.
. Sélectionnez *Désinstaller ce programme*.
