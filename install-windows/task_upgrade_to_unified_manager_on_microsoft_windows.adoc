= Mettez à niveau Active IQ Unified Manager sous Windows
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez mettre à niveau Unified Manager 9.14 ou 9.16 vers la version 9.18 en téléchargeant et en exécutant le fichier d'installation sur la plateforme Windows.

.Avant de commencer
* Le système sur lequel vous effectuez la mise à niveau d'Unified Manager doit répondre aux exigences système et logicielles.
+
Voir link:concept_virtual_infrastructure_or_hardware_system_requirements.html["Configuration matérielle requise du système"].

+
Voir link:reference_windows_software_and_installation_requirements.html["Logiciels Windows et exigences d'installation"].

+
[NOTE]
====
À partir d'Unified Manager 9.5, OpenJDK est inclus dans le package d'installation et installé automatiquement. Oracle Java n'est plus pris en charge à partir d'Unified Manager 9.5.

====
+
[NOTE]
====
Assurez-vous que Microsoft .NET 4.5.2 ou une version supérieure est installée sur votre système avant de commencer la mise à niveau.

====
* MySQL Community Edition est automatiquement mis à niveau lors de la mise à niveau de Unified Manager. Si la version de MySQL installée sur votre système est antérieure à 8.4.10, le processus de mise à niveau de Unified Manager met automatiquement MySQL à niveau vers 8.4.10. Vous ne devez pas effectuer de mise à niveau autonome d'une version antérieure de MySQL vers 8.4.10.
* Tous les clusters sont pris en charge, à l’exception des systèmes ASA r2.
* Vous devez disposer des privilèges d'administrateur Windows. Assurez-vous que votre nom d'utilisateur ne commence pas par un point d'exclamation "`!`". Installation of Unified Manager might fail if the user name of user running the installation begins with "`!`".
* Vous devez disposer d'identifiants valides pour vous connecter au site d'assistance NetApp.
* Pour éviter la perte de données, vous auriez dû créer une sauvegarde de la machine Unified Manager au cas où un problème surviendrait lors de la mise à niveau.
* Vous devez disposer de suffisamment d'espace disque pour effectuer la mise à niveau.
+
L'espace disponible sur le disque d'installation doit être supérieur de 2,5 Go à la taille du répertoire de données. Si l'espace libre est insuffisant, la mise à niveau s'interrompt et un message d'erreur s'affiche, indiquant l'espace à ajouter.

* Lors de la mise à niveau, il vous sera peut-être demandé de confirmer si vous souhaitez conserver les paramètres par défaut précédents pour la conservation des données de performance pendant 13 mois ou les remplacer par 6 mois. Après confirmation, les données historiques de performance datant de plus de 6 mois sont supprimées.
* Avant la mise à niveau, vous devez fermer tous les fichiers ou dossiers ouverts dans _<InstallDir>\JDK_ et _MySQL Data Directory_.
* Si un logiciel antivirus est actif sur votre système Windows, la mise à niveau d'Unified Manager risque d'échouer. Il est recommandé de désactiver tout logiciel antivirus avant de procéder à la mise à niveau d'Unified Manager.


Pendant la mise à niveau, Unified Manager est indisponible. Veuillez terminer toutes les opérations en cours avant de mettre à niveau Unified Manager.

Si Unified Manager est associé à une instance de OnCommand Workflow Automation et que de nouvelles versions logicielles sont disponibles pour les deux produits, vous devez déconnecter les deux produits, puis configurer une nouvelle connexion Workflow Automation après avoir effectué les mises à niveau. Si vous effectuez une mise à niveau d'un seul des produits, vous devez alors vous connecter à Workflow Automation après la mise à niveau et vérifier qu'il continue à acquérir des données depuis Unified Manager.

.Étapes
. Connectez-vous au site de support NetApp et accédez à la page de téléchargement d’Unified Manager :
+
https://mysupport.netapp.com/site/products/all/details/activeiq-unified-manager/downloads-tab["Site de support NetApp"^].

. Sélectionnez la version requise de Unified Manager et acceptez le contrat de licence de l’utilisateur final (EULA).
. Téléchargez le fichier d'installation Windows ou le fichier zip de Unified Manager dans un répertoire cible du système Windows. Extrayez le fichier zip, si nécessaire, puis accédez au répertoire dans lequel se trouve le fichier d'installation. Cliquez avec le bouton droit de la souris sur le fichier exécutable du programme d'installation de Unified Manager (.exe) et exécutez-le en tant qu'administrateur.
+
Unified Manager vous affiche le message suivant :

+
[listing]
----
This setup will perform an upgrade of Unified Manager. Do you want to continue?
----
. Cliquez sur *Oui*, puis sur *Suivant*.
. Saisissez le mot de passe root MySQL84 défini lors de l'installation, puis cliquez sur *Suivant*.
. Lancez l’interface utilisateur Web dans une nouvelle fenêtre d’un navigateur Web pris en charge et connectez-vous pour utiliser la version mise à jour d’Unified Manager.
. Si vous avez un logiciel antivirus actif installé sur votre système Windows, veillez à exclure manuellement les chemins suivants de l'analyse antivirus une fois la mise à niveau terminée :
+
** Répertoire de données Unified Manager
** Répertoire d'installation d'Unified Manager
** Répertoire de données MySQL




[NOTE]
====
Pour effectuer une mise à niveau silencieuse d'Unified Manager, exécutez la commande suivante :
`ActiveIQUnifiedManager-<version\>.exe /s /v"MYSQL_PASSWORD=<password> /qn /l*v <system_drive>:\install.log"`
