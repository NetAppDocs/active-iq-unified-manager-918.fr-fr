= Comprendre comment l'ajout de disques affecte la disposition des agrégats dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez ajouter des disques à un agrégat pour augmenter sa capacité de stockage et ses performances. Après l'ajout des disques, l'amélioration des performances ne sera visible qu'après la reconstruction de l'agrégat.

Lorsque vous recevez un événement de seuil défini par le système sur la page Détails de l'événement, le texte de description de l'événement indique le nom de l'agrégat qui présente le problème. Vous pouvez ajouter des disques et reconstruire les données sur cet agrégat.

Les disques que vous ajoutez à l'agrégat doivent déjà être présents dans le cluster. Si le cluster ne dispose pas de disques supplémentaires, vous devrez peut-être contacter votre administrateur ou acheter davantage de disques. Vous pouvez utiliser ONTAP System Manager ou les commandes ONTAP pour ajouter des disques à un agrégat.
