= Analysez les événements issus des seuils de performance dynamiques dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les événements générés par les seuils dynamiques indiquent que le temps de réponse réel (latence) d'un workload est trop élevé ou trop faible par rapport à la plage de temps de réponse attendue. Vous utilisez la page « Détails de l'événement » pour analyser l'événement de performance et prendre les mesures correctives nécessaires afin de rétablir des performances normales.

[NOTE]
====
Les seuils de performance dynamiques ne sont pas activés sur les systèmes Cloud Volumes ONTAP, ONTAP Edge ou ONTAP Select.
