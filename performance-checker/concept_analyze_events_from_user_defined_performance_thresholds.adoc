= Analysez les événements à partir des seuils de performance définis par l'utilisateur dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les événements générés par des seuils définis par l'utilisateur indiquent qu'un compteur de performance d'un objet de stockage donné, par exemple un agrégat ou un volume, a dépassé le seuil défini dans la stratégie. Cela signifie que l'objet du cluster rencontre un problème de performance.

Vous utilisez la page de détails de l’événement pour analyser l’événement de performance et prendre les mesures correctives nécessaires afin de rétablir des performances normales.
