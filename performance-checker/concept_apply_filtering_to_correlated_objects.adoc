= Filtrer les objets corrélés dans la grille Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Le filtrage vous permet d'afficher un sous-ensemble plus restreint et mieux défini d'objets dans la grille. Par exemple, si vous avez 25 volumes dans la grille, le filtrage vous permet de visualiser uniquement ceux dont le débit est inférieur à 90 Mo/s ou dont la latence est supérieure à 1 ms/op.
