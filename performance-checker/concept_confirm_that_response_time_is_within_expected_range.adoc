= Vérifiez que la latence se situe dans la plage attendue dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Lorsqu'un composant du cluster est en conflit, les workloads de volume qui l'utilisent peuvent présenter un temps de réponse (latence) réduit. Vous pouvez examiner la latence de chaque workload victime sur le composant en conflit afin de confirmer que sa latence réelle se situe dans la plage attendue. Vous pouvez également cliquer sur le nom d'un volume pour afficher les données historiques du volume.

Si l'événement de performance est à l'état obsolète, la latence de chaque victime impliquée dans l'événement peut être revenue dans la plage attendue.
