= Améliorez les performances des charges de travail en activant Flash Pool sur un agrégat de stockage dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez améliorer les performances du workload en activant la fonctionnalité Flash Pool sur un agrégat. Un Flash Pool est un agrégat qui intègre à la fois des HDD et des SSD. Les HDD servent au stockage principal, tandis que les SSD fournissent un cache de lecture et d'écriture haute performance afin d'améliorer les performances de l'agrégat.

Dans Unified Manager, la page Détails de l'événement affiche le nom de l'agrégat en conflit. Vous pouvez utiliser ONTAP System Manager ou les commandes ONTAP pour voir si Flash Pool est activé pour un agrégat. Si vous avez des SSD installés, vous pouvez l'activer à l'aide de l'interface de ligne de commande. Si vous avez des SSD installés, vous pouvez exécuter la commande suivante sur l'agrégat pour voir si Flash Pool est activé : `*cluster::> storage aggregate show -aggregate aggr_name -field hybrid-enabled*`

Dans cette commande, `_aggr_name_` correspond au nom de l’agrégat, tel que l’agrégat en contention.

Pour plus d'informations sur Flash Pool et les exigences relatives à son utilisation, consultez le _Clustered Data ONTAP Physical Storage Management Guide_.
