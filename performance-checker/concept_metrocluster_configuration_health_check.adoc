= Vérifiez l'état de la configuration MetroCluster dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez utiliser Unified Manager pour examiner l’état des clusters dans une configuration MetroCluster sur IP ou FC. L’état et les événements associés vous aident à déterminer si des problèmes matériels ou logiciels peuvent affecter les performances de vos workloads.

Si vous configurez Unified Manager pour envoyer des alertes par e-mail, vous pouvez consulter votre messagerie pour détecter tout problème d'intégrité sur le cluster local ou distant susceptible d'avoir contribué à un incident de performance. Dans l'interface graphique d'Unified Manager, vous pouvez sélectionner *Gestion des événements* pour afficher la liste des événements en cours, puis utiliser les filtres pour n'afficher que les événements de configuration MetroCluster.

Pour plus d'informations, voir link:../health-checker/task_check_health_of_clusters_in_metrocluster_configuration.html["Vérification de l'état des clusters dans une configuration MetroCluster"]
