= Surveillez les performances du cluster depuis la page d'accueil « Performances du cluster » dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La page d’accueil du cluster de performances affiche l’état général des performances d’un cluster sélectionné surveillé par une instance de Unified Manager. Cette page vous permet d’évaluer les performances globales d’un cluster spécifique et de repérer, localiser ou attribuer rapidement pour résolution tout événement spécifique au cluster qui est identifié.
