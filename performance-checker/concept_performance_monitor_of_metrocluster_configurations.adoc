= Surveillez les performances de MetroCluster avec Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager vous permet de surveiller le débit d'écriture entre les clusters dans une configuration MetroCluster afin d'identifier les workloads présentant un débit d'écriture élevé.

Si ces workloads hautes performances entraînent des temps de réponse d'E/S élevés pour d'autres volumes du cluster local, Unified Manager déclenche des événements de performance pour vous en informer.


NOTE: Unified Manager traite les clusters d'une configuration MetroCluster comme des clusters individuels. Il ne fait pas de distinction entre les clusters partenaires et ne corrèle pas le débit d'écriture de chaque cluster.

Lorsqu'un cluster local dans une configuration MetroCluster réplique ses données vers son cluster partenaire, les données sont écrites dans la NVRAM, puis transférées via les liaisons intercommutateurs (ISL) vers les agrégats distants. Unified Manager analyse la NVRAM afin d'identifier les workloads dont le débit d'écriture élevé entraîne une surutilisation de la NVRAM, provoquant ainsi une contention au niveau de la NVRAM.

Les workloads dont l’écart du temps de réponse a dépassé le seuil de performance sont appelés « victimes », et les workloads dont l’écart du débit d’écriture vers la NVRAM est plus élevé que d’habitude, provoquant la contention, sont appelés « bullies ». Étant donné que seules les requêtes d’écriture sont mises en miroir vers le cluster partenaire, Unified Manager n’analyse pas le débit de lecture.

Vous pouvez visualiser le débit de n'importe lequel des clusters d'une configuration MetroCluster en analysant les workloads des LUN et des volumes correspondants à partir des écrans suivants. Vous pouvez filtrer les résultats par cluster. Dans le volet de navigation de gauche :

* *Stockage > Clusters > Performances : Tous les clusters* Voir
* vue *Stockage > Volumes > Performance : Tous les volumes*.
* *Stockage > LUN > Performances: vue de toutes les LUN*.
* *Analyse des workloads > Tous les workloads*
