= Utilisez les interfaces d'Active IQ Unified Manager pour gérer les performances du système de stockage
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ces sections contiennent des informations sur les deux interfaces utilisateur qu'Active IQ Unified Manager fournit pour résoudre les problèmes de capacité, de disponibilité et de protection du stockage des données. Les deux interfaces utilisateur sont l'interface utilisateur web Unified Manager et la console de maintenance.

Si vous souhaitez utiliser les fonctionnalités de protection d'Unified Manager, vous devez également installer et configurer OnCommand Workflow Automation (WFA).



[[unified-manager-web-ui]]
== interface utilisateur Web de Unified Manager

L'interface utilisateur Web de Unified Manager permet à un administrateur de surveiller et de résoudre les problèmes de cluster liés à la capacité, à la disponibilité et à la protection du stockage des données.

Ces sections décrivent certains workflows courants qu'un administrateur peut suivre pour résoudre les problèmes de capacité de stockage, de disponibilité des données ou de protection affichés dans l'interface utilisateur Web de Unified Manager.



[[maintenance-console]]
== Console de maintenance

La console de maintenance Unified Manager permet à un administrateur de surveiller, de diagnostiquer et de résoudre les problèmes liés au système d'exploitation, aux mises à niveau de version, aux accès utilisateurs et au réseau du serveur Unified Manager lui-même. Si l'interface utilisateur web de Unified Manager est indisponible, la console de maintenance est le seul moyen d'accéder à Unified Manager.

Vous pouvez utiliser ces informations pour accéder à la console de maintenance et l’utiliser pour résoudre les problèmes liés au fonctionnement du serveur Unified Manager.
