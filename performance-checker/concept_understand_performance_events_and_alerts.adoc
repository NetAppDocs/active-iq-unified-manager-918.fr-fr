= Comprendre les événements et alertes de performance dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les événements de performance sont des incidents liés aux performances des workloads sur un cluster. Ils vous aident à identifier les workloads dont les temps de réponse sont lents. Associés aux événements de santé survenus au même moment, ils vous permettent de déterminer les problèmes qui ont pu causer ces temps de réponse lents ou y contribuer.

Lorsque Unified Manager détecte plusieurs occurrences de la même condition d'événement pour le même composant du cluster, il traite toutes les occurrences comme un seul événement, et non comme des événements distincts.

Vous pouvez configurer des alertes pour envoyer automatiquement des notifications par e-mail lorsque des événements de performance d'un certain niveau de gravité se produisent.
