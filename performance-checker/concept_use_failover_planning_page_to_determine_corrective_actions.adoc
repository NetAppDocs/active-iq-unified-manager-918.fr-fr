= Déterminez les actions correctives à partir de la page Performance/Node Failover Planning dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
En vous basant sur les informations affichées sur la page « Planification des performances/basculement des nœuds », vous pouvez prendre des mesures pour éviter qu'un basculement n'entraîne une baisse des performances d'une paire haute disponibilité en dessous d'un niveau acceptable.

Par exemple, pour réduire l'impact estimé d'un basculement sur les performances, vous pouvez déplacer certains volumes ou LUN d'un nœud de la paire haute disponibilité vers d'autres nœuds du cluster. Cela garantit que le nœud principal peut continuer à fournir des performances acceptables après un basculement.
