= Créez des politiques de seuil pour la planification du basculement des nœuds dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez créer une politique de seuil de nœud afin de recevoir une notification sur la page Performance/Node Failover Planning lorsqu'un basculement potentiel dégraderait les performances du nœud de prise en charge à un niveau inacceptable.

La stratégie de seuil de performance définie par le système, nommée « `Node HA pair over-utilized` », génère un événement d'avertissement si le seuil est dépassé pendant six périodes de collecte consécutives (30 minutes). Le seuil est considéré comme dépassé si la capacité de performance combinée utilisée des nœuds d'une paire haute disponibilité dépasse 200 %.

L'événement généré par la politique de seuil définie par le système vous avertit qu'un basculement entraînera une augmentation inacceptable de la latence du nœud de takeover. Lorsqu'un tel événement est généré pour un nœud donné, vous pouvez accéder à la page Performance/Node Failover Planning de ce nœud afin d'afficher la valeur de latence prévue due à un basculement.

Outre l'utilisation de cette stratégie de seuil définie par le système, vous pouvez créer des stratégies de seuil à l'aide du compteur « `Performance Capacity Used - Takeover` », puis appliquer la stratégie aux nœuds sélectionnés. Le fait de spécifier un seuil inférieur à 200 % vous permet de recevoir un événement avant que le seuil de la stratégie définie par le système ne soit dépassé. Vous pouvez également spécifier une durée minimale de dépassement du seuil inférieure à 30 minutes si vous souhaitez être averti avant que l'événement de la stratégie définie par le système ne soit généré.

Par exemple, vous pouvez définir une politique de seuil pour générer un événement d'avertissement si la capacité de performance combinée utilisée des nœuds d'une paire haute disponibilité dépasse 175 % pendant plus de 10 minutes. Vous pouvez appliquer cette politique à Node1 et Node2, qui forment une paire haute disponibilité. Après avoir reçu une notification d'événement d'avertissement pour Node1 ou Node2, vous pouvez afficher la page Performance/Node Failover Planning de ce nœud pour évaluer l'impact estimé sur les performances du nœud de reprise. Vous pouvez prendre des mesures correctives pour éviter de surcharger le nœud de reprise si un basculement se produit. Si vous intervenez lorsque la capacité de performance combinée utilisée des nœuds est inférieure à 200 %, la latence du nœud de reprise n'atteint pas un niveau inacceptable, même si un basculement se produit pendant cette période.
