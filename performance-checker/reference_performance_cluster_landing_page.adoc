= Consultez la page d'accueil du cluster de performance dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La page d'accueil du cluster de performances affiche un aperçu général de l'état des performances du cluster sélectionné. La page vous permet d'accéder aux détails complets de chaque compteur de performances des objets de stockage du cluster sélectionné.

La page d'accueil du cluster de performance comprend quatre onglets qui répartissent les détails du cluster en quatre domaines d'information :

* Page récapitulative
+
** volet Événements du cluster
** Graphiques de performance MB/s et IOPS
** Volet des objets gérés


* page des meilleures performances
* page Explorer
* Page d'information
