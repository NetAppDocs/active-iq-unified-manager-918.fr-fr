= Comprendre les compteurs de performance suivis à l'aide de seuils dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Certains compteurs de performance courants, tels que les IOPS et les Mo/s, peuvent avoir des seuils définis pour tous les objets de stockage. D'autres compteurs peuvent avoir des seuils définis uniquement pour certains objets de stockage.



[[available-performance-counters]]
== Compteurs de performances disponibles

|===
| Objet de stockage | Compteur de performances | Description 


 a| 
Cluster
 a| 
Op E/S par sec
 a| 
Nombre moyen d'opérations d'entrée/sortie traitées par le cluster par seconde.



 a| 
Mo/s
 a| 
Nombre moyen de mégaoctets de données transférés vers et depuis ce cluster par seconde.



 a| 
Nœud
 a| 
Op E/S par sec
 a| 
Nombre moyen d'opérations d'entrée/sortie que le nœud traite par seconde.



 a| 
Mo/s
 a| 
Nombre moyen de mégaoctets de données transférés vers et depuis ce nœud par seconde.



 a| 
Latence
 a| 
Nombre moyen de millisecondes nécessaires au nœud pour répondre aux requêtes de l'application.



 a| 
Utilisation
 a| 
Pourcentage moyen d'utilisation du processeur et de la mémoire vive du nœud.



 a| 
Capacité de performance utilisée
 a| 
Pourcentage moyen de capacité de performance consommée par le nœud.



 a| 
Capacité de performance utilisée - Prise de contrôle
 a| 
Pourcentage moyen de capacité de performance consommée par le nœud, plus la capacité de performance de son nœud partenaire.



 a| 
Agrégat
 a| 
Op E/S par sec
 a| 
Nombre moyen d'opérations d'entrée/sortie que l'agrégat traite par seconde.



 a| 
Mo/s
 a| 
Nombre moyen de mégaoctets de données transférés vers et depuis cet agrégat par seconde.



 a| 
Latence
 a| 
Nombre moyen de millisecondes nécessaires à l’agrégat pour répondre aux requêtes de l’application.



 a| 
Utilisation
 a| 
Pourcentage moyen des disques de l'agrégat qui sont utilisés.



 a| 
Capacité de performance utilisée
 a| 
Pourcentage moyen de la capacité de performance consommée par l’agrégat.



 a| 
VM de stockage
 a| 
Op E/S par sec
 a| 
Nombre moyen d'opérations d'entrée/sortie traitées par le SVM par seconde.



 a| 
Mo/s
 a| 
Nombre moyen de mégaoctets de données transférés vers et depuis cette SVM par seconde.



 a| 
Latence
 a| 
Nombre moyen de millisecondes nécessaires au SVM pour répondre aux requêtes de l'application.



 a| 
Volume
 a| 
Op E/S par sec
 a| 
Nombre moyen d'opérations d'entrée/sortie que le volume traite par seconde.



 a| 
Mo/s
 a| 
Nombre moyen de mégaoctets de données transférés à destination et en provenance de ce volume par seconde.



 a| 
Latence
 a| 
Nombre moyen de millisecondes que le volume met pour répondre aux requêtes de l'application.



 a| 
Taux de défauts du cache
 a| 
Pourcentage moyen de requêtes de lecture provenant d’applications clientes qui sont satisfaites par le volume plutôt que par le cache.



 a| 
LUN
 a| 
Op E/S par sec
 a| 
Nombre moyen d'opérations d'entrée/sortie traitées par le LUN par seconde.



 a| 
Mo/s
 a| 
Nombre moyen de mégaoctets de données transférés vers et depuis ce LUN par seconde.



 a| 
Latence
 a| 
Nombre moyen de millisecondes nécessaires au LUN pour répondre aux requêtes de l'application.



 a| 
Espace de noms
 a| 
Op E/S par sec
 a| 
Nombre moyen d'opérations d'entrée/sortie que le namespace traite par seconde.



 a| 
Mo/s
 a| 
Nombre moyen de mégaoctets de données transférés vers et depuis ce namespace par seconde.



 a| 
Latence
 a| 
Nombre moyen de millisecondes nécessaires au namespace pour répondre aux requêtes de l'application.



 a| 
Port
 a| 
Utilisation de la bande passante
 a| 
Pourcentage moyen de la bande passante disponible du port utilisée.



 a| 
Mo/s
 a| 
Nombre moyen de mégaoctets de données transférés vers et depuis ce port par seconde.



 a| 
Interface réseau (LIF)
 a| 
Mo/s
 a| 
Nombre moyen de mégaoctets de données transférés vers et depuis cette LIF par seconde.

|===
