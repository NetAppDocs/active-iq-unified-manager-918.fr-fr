= Déplacez les charges de travail vers un autre nœud d'une paire haute disponibilité dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez utiliser Unified Manager pour identifier un agrégat sur un nœud d’une autre paire haute disponibilité moins sollicité que la paire haute disponibilité sur laquelle vos workloads s’exécutent actuellement. Vous pouvez ensuite déplacer les volumes sélectionnés vers des agrégats de cette nouvelle paire haute disponibilité. Le déplacement de workloads très performants vers un agrégat sur un nœud moins sollicité permet aux workloads sur les deux nœuds de fonctionner plus efficacement.

.Avant de commencer
* Vous devez avoir le rôle Operator, Application Administrator ou Storage Administrator.
* Votre cluster doit comporter au minimum deux paires haute disponibilité ; vous ne pouvez pas utiliser cette procédure de correction si votre cluster ne comporte qu’une seule paire haute disponibilité.
* Vous devez avoir noté les noms des deux nœuds de la paire haute disponibilité qui rencontrent actuellement le problème de performance.
* Vous devez avoir enregistré la date et l'heure auxquelles les nœuds ont reçu l'événement de performance.
* Unified Manager doit avoir collecté et analysé au moins un mois de données de performance.


Ces étapes vous aident à identifier les ressources suivantes afin que vous puissiez déplacer les workloads hautes performances vers un nœud moins utilisé sur une autre paire haute disponibilité :

* Les nœuds d'une autre paire haute disponibilité sur le même cluster qui sont moins utilisés
* Les agrégats des nouveaux nœuds qui sont les moins utilisés
* Les volumes les plus performants sur les nœuds actuels


.Étapes
. Identifiez les nœuds qui font partie d’une paire haute disponibilité différente sur le même cluster :
+
.. Dans le volet de navigation de gauche, cliquez sur *Storage* > *Clusters* et sélectionnez *Performance* > *All Clusters* dans le menu *View*.
+
La vue « Performances : Tous les clusters » s’affiche.

.. Cliquez sur le nombre dans le champ *Nombre de nœuds* pour le cluster actuel.
+
La vue « Performances : Tous les nœuds » s'affiche.

.. Notez les noms des nœuds qui appartiennent à des paires haute disponibilité différentes de la paire haute disponibilité qui présente actuellement le problème de performance.


. Identifiez un nœud de la nouvelle paire haute disponibilité qui est le moins utilisé :
+
.. Cliquez sur la colonne *Utilisation* pour trier les nœuds du moins utilisé au plus utilisé.
+
Vous pouvez également identifier les nœuds disposant de la plus grande *capacité libre*. Cela vous fournit une liste de nœuds potentiels vers lesquels vous pourriez déplacer des workloads.

.. Notez le nom du nœud vers lequel vous souhaitez déplacer les workloads.


. Identifiez sur le nouveau nœud l’agrégat le moins utilisé :
+
.. Dans le volet de navigation de gauche, cliquez sur *Stockage* > *Agrégats* et sélectionnez *Performances* > *Tous les agrégats* dans le menu Affichage.
+
La vue « Performances : Tous les agrégats » s’affiche.

.. Cliquez sur *Filtrage*, sélectionnez *Nœud* dans le menu déroulant de gauche, saisissez le nom du nœud dans le champ de texte, puis cliquez sur *Appliquer le filtre*.
+
La vue « Performances : Tous les agrégats » s’affiche à nouveau avec la liste des agrégats disponibles sur ce nœud.

.. Cliquez sur la colonne *Utilisation* pour trier les agrégats du moins utilisé au plus utilisé.
+
Vous pouvez également identifier les agrégats présentant la plus grande *capacité libre*. Ceci fournit une liste d'agrégats potentiels vers lesquels vous pourriez déplacer des workloads.

.. Notez le nom de l'agrégat vers lequel vous souhaitez déplacer les workloads.


. Identifiez les workloads les plus performants parmi les nœuds ayant reçu l'événement :
+
.. Retournez à la page des détails de l’*Event* pour l’événement.
.. Dans le champ *Volumes affectés*, cliquez sur le lien correspondant au nombre de volumes pour le premier nœud.
+
La vue « Performances : Tous les volumes » affiche une liste filtrée des volumes présents sur ce nœud.

.. Cliquez sur la colonne *Capacité totale* pour trier les volumes selon l'espace alloué le plus important.
+
Cela fournit une liste des volumes potentiels que vous souhaiterez peut-être déplacer.

.. Notez les noms des volumes que vous souhaitez déplacer, ainsi que les noms des agrégats actuels sur lesquels ils se trouvent.
.. Effectuez les étapes 4c et 4d pour le deuxième nœud qui faisait partie de cet événement afin d'identifier les volumes possibles que vous souhaitez également déplacer à partir de ce nœud.


. Déplacez les volumes vers les agrégats que vous avez identifiés comme ayant une faible utilisation sur le nouveau nœud.
+
Vous pouvez effectuer l'opération de déplacement à l'aide de ONTAP System Manager, OnCommand Workflow Automation, des commandes ONTAP ou d'une combinaison de ces outils.



Après quelques jours, vérifiez si vous recevez le même type d'événements de ce nœud ou de cet agrégat.
