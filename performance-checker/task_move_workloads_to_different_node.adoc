= Déplacez les charges de travail vers un autre nœud dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez utiliser Unified Manager pour identifier un agrégat sur un autre nœud moins sollicité que le nœud sur lequel vos workloads s'exécutent actuellement, puis déplacer les volumes sélectionnés vers cet agrégat. Le déplacement des workloads les plus performants vers un agrégat sur un nœud moins sollicité permet aux workloads sur les deux nœuds de s'exécuter plus efficacement.

.Avant de commencer
* Vous devez avoir le rôle Operator, Application Administrator ou Storage Administrator.
* Vous avez dû noter le nom du nœud qui rencontre actuellement un problème de performance.
* Vous devez avoir enregistré la date et l'heure auxquelles le nœud a reçu l'événement de performance.
* Unified Manager doit avoir collecté et analysé des données de performance pendant un mois ou plus.


Cette procédure vous aide à identifier les ressources suivantes afin que vous puissiez déplacer les workloads à hautes performances vers un nœud moins utilisé :

* Les nœuds du même cluster qui disposent de la plus grande capacité de performance disponible
* Les agrégats du nouveau nœud qui disposent de la plus grande capacité de performances disponible
* Les volumes les plus performants sur le nœud actuel


.Étapes
. Identifiez un nœud du cluster qui dispose de la plus grande capacité de performances disponible :
+
.. Sur la page *Détails de l'événement*, cliquez sur le nom du cluster sur lequel se trouve le nœud.
+
Les détails du cluster sont affichés sur la page de destination Performance/Cluster.

.. Dans l'onglet *Résumé*, cliquez sur *Nœuds* dans le volet *Objets gérés*.
+
La liste des nœuds de ce cluster est affichée.

.. Cliquez sur la colonne *Capacité de performance utilisée* pour trier les nœuds par pourcentage d'utilisation le plus faible.
+
Ceci fournit une liste de nœuds potentiels vers lesquels vous pourriez déplacer des workloads.

.. Notez le nom du nœud vers lequel vous souhaitez déplacer les workloads.


. Identifiez sur le nouveau nœud l’agrégat le moins utilisé :
+
.. Dans le volet de navigation de gauche, cliquez sur *Stockage* > *Agrégats* et sélectionnez *Performances* > *Tous les agrégats* dans le menu Affichage.
+
La vue « Performances : Tous les agrégats » s’affiche.

.. Cliquez sur *Filtrage*, sélectionnez *Nœud* dans le menu déroulant de gauche, saisissez le nom du nœud dans le champ de texte, puis cliquez sur *Appliquer le filtre*.
+
La vue « Performances : Tous les agrégats » s’affiche à nouveau avec la liste des agrégats disponibles sur ce nœud.

.. Cliquez sur la colonne *Capacité de performance utilisée* pour trier les agrégats du moins utilisé au plus utilisé.
+
Cela fournit une liste des agrégats potentiels vers lesquels vous pourriez déplacer des workloads.

.. Notez le nom de l'agrégat vers lequel vous souhaitez déplacer les workloads.


. Identifiez les workloads les plus performants du nœud qui a reçu l'événement :
+
.. Revenez à la page *Détails de l'événement* pour cet événement.
.. Dans le champ *Volumes concernés*, cliquez sur le lien correspondant au nombre de volumes.
+
La vue « Performances : Tous les volumes » affiche une liste filtrée des volumes présents sur ce nœud.

.. Cliquez sur la colonne *Capacité totale* pour trier les volumes selon l'espace alloué le plus important.
+
Ceci fournit une liste des volumes potentiels que vous souhaiterez peut-être déplacer.

.. Notez les noms des volumes que vous souhaitez déplacer, ainsi que les noms des agrégats actuels sur lesquels ils se trouvent.


. Déplacez les volumes vers les agrégats que vous avez identifiés comme disposant de la plus grande capacité de performances disponible sur le nouveau nœud.
+
Vous pouvez effectuer l'opération de déplacement à l'aide de ONTAP System Manager, OnCommand Workflow Automation, des commandes ONTAP ou d'une combinaison de ces outils.



Après quelques jours, vous pourrez vérifier si vous recevez le même type d'événements de ce nœud ou de cet agrégat.
