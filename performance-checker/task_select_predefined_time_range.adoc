= Sélectionnez une plage horaire prédéfinie dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sélectionner une période prédéfinie est un moyen rapide et efficace de personnaliser et de cibler les données affichées lors de la consultation des données de performance des objets du cluster. Lors de la sélection d’une période prédéfinie, des données sur une période allant jusqu’à 13 mois sont disponibles.

.Étapes
. En haut à droite de la page *Performance Explorer*, cliquez sur *Time Range*.
. Dans le panneau *Time Range Selection*, à droite, sélectionnez une plage horaire prédéfinie.
. Cliquez sur *Apply Range*.
