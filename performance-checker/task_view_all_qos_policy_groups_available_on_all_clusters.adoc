= Consultez les groupes de règles QoS disponibles sur tous les clusters dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez afficher une liste de tous les groupes de stratégies QoS disponibles sur les clusters surveillés par Unified Manager. Cela inclut les stratégies QoS traditionnelles, les stratégies QoS adaptatives et les stratégies QoS gérées par les stratégies de niveau de service de performances de Unified Manager.

.Étapes
. Dans le volet de navigation de gauche, cliquez sur *Stockage* > *Groupes de stratégies QoS*.
+
La vue Performance: Traditional QoS Policy Groups s’affiche par défaut.

. Consultez les paramètres de configuration détaillés de chaque groupe de stratégie QoS traditionnelle disponible.
. Cliquez sur le bouton d’extension (image:../media/chevron_down.gif[""]) à côté du nom du groupe de stratégie QoS pour afficher plus de détails sur ce groupe de stratégie.
. Dans le menu Affichage, sélectionnez l’une des options supplémentaires pour afficher tous les groupes de stratégies QoS adaptatifs ou pour afficher tous les groupes de stratégies QoS créés à l’aide de Unified Manager Performance Service Levels.
