= Consultez les détails de l'événement dans la chronologie des événements d'Active IQ Unified Manager.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez consulter tous les événements et leurs détails associés dans le volet Chronologie des événements de Performance Explorer. Cette méthode rapide et efficace permet de visualiser tous les événements liés à l'état et aux performances de l'objet racine pendant une période donnée, ce qui peut s'avérer utile pour résoudre les problèmes de performances.

Le volet Chronologie des événements affiche les événements critiques, d'erreur, d'avertissement et d'information survenus sur l'objet racine pendant la période sélectionnée. Chaque niveau de gravité d'événement possède sa propre chronologie. Les événements uniques et multiples sont représentés par un point d'événement sur la chronologie. Vous pouvez placer votre curseur sur un point d'événement pour afficher les détails de l'événement. Pour augmenter la granularité visuelle des événements multiples, vous pouvez réduire la période. Cela répartit les événements multiples en événements individuels, ce qui vous permet d'afficher et d'examiner séparément chaque événement.

Chaque point d'événement de performance sur la chronologie des événements s'aligne verticalement avec un pic correspondant sur les courbes de tendance des graphiques des compteurs affichés sous la chronologie des événements. Cela fournit une corrélation visuelle directe entre les événements et les performances globales. Les événements de santé sont également affichés sur la chronologie, mais ces types d'événements ne correspondent pas nécessairement à un pic dans l'un des graphiques de performance.

.Étapes
. Dans le volet *Chronologie des événements*, placez le curseur sur un point d'événement de la chronologie pour afficher un résumé de l'événement ou des événements à ce point précis.
+
Une boîte de dialogue contextuelle affiche des informations sur les types d'événements, la date et l'heure auxquelles les événements se sont produits, l'état et la durée de l'événement.

. Afficher les détails complets d'un ou plusieurs événements :
+
|===
| Pour ce faire... | Cliquez ici... 


 a| 
Afficher les détails d'un seul événement
 a|

 a|
