= Affichez le trafic IOPS SVM par protocole dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez consulter des informations détaillées sur les IOPS d'une SVM à l'aide de la page Performance/SVM Explorer. Le graphique de compteur « IOPS - Total » affiche l'utilisation totale des IOPS sur la SVM, tandis que le graphique de compteur « IOPS - Breakdown » est utile pour déterminer l'impact des IOPS de lecture, d'écriture et autres sur la SVM.

De plus, le graphique IOPS - Protocoles présente une comparaison détaillée du trafic IOPS pour chaque protocole utilisé sur la SVM. Les protocoles suivants sont disponibles :

* CIFS
* NFS
* FCP
* iSCSI
* NVMe-FC


.Étapes
. Sur la page *Performance/SVM Explorer* de votre SVM sélectionné, dans le graphique IOPS, sélectionnez *Protocoles* dans le menu déroulant.
+
Le graphique IOPS - Protocoles s'affiche.

. Pour afficher une version agrandie du graphique, sélectionnez *Zoom View*.
+
Le tableau comparatif avancé des protocoles IOPS s'affiche. Vous pouvez limiter la comparaison en désélectionnant ou en sélectionnant l'image:../media/eye_icon.gif["icône en forme d'œil"]associé à un protocole.

. Pour afficher les valeurs spécifiques, déplacez votre curseur dans la zone de l’un ou l’autre graphique pour faire apparaître la fenêtre contextuelle.
