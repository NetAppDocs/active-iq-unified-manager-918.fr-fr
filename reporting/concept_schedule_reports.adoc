= Planifiez des rapports dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Une fois que vous disposez d'une vue que vous souhaitez réutiliser et partager sous forme de rapport, vous pouvez la planifier à l'aide d'Active IQ Unified Manager. Vous pouvez gérer les rapports planifiés, en modifiant les destinataires et la fréquence de distribution pour chaque planification de rapport.

Vous pouvez programmer la plupart des vues ou des pages d’inventaire dans Unified Manager. Les exceptions sont les événements, qui sont des rapports que vous pouvez télécharger au format CSV, mais vous ne pouvez pas programmer leur régénération ni leur partage. Vous ne pouvez pas non plus télécharger ni programmer les tableaux de bord, les favoris ou les pages de configuration.

À partir d'Active IQ Unified Manager 9.8, vous pouvez télécharger des vues au format Microsoft® Excel et les personnaliser. Vous pouvez utiliser des fonctionnalités Excel avancées telles que les tris complexes, les filtres multicouches, les tableaux croisés dynamiques et les graphiques. Une fois satisfait du rapport Excel obtenu, vous pouvez importer le fichier Excel pour l'utiliser chaque fois que le rapport est planifié et partagé.

Vous pouvez programmer les vues intégrées ou les vues que vous personnalisez. Vous pouvez choisir le type de fichier à envoyer, soit CSV, PDF ou XSLX. Lorsque vous programmez un rapport pour la première fois, vous pouvez le télécharger et vous désigner comme seul destinataire pour voir le rapport tel que vos destinataires le verront.
