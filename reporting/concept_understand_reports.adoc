= Comprendre les rapports dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les rapports affichent des informations détaillées sur le stockage, le réseau, la qualité de service et les relations de protection, vous aidant ainsi à identifier et à résoudre les problèmes potentiels avant qu'ils ne surviennent.

Lorsque vous personnalisez une vue, vous pouvez l'enregistrer sous un nom unique pour une utilisation ultérieure. Vous pouvez programmer l'exécution régulière d'un rapport basé sur cette vue et le partager avec d'autres. Vous pouvez également télécharger la vue au format Excel pour la personnaliser à l'aide des fonctionnalités avancées d'Excel, puis importer ce fichier dans Unified Manager. Si vous programmez un rapport à partir de cette vue, celui-ci utilisera le fichier Excel importé pour générer des rapports robustes que vous pourrez partager.

Vous pouvez gérer tous les rapports programmés depuis la page « Planification des rapports ».

[NOTE]
====
Vous devez disposer du rôle d'administrateur d'applications ou d'administrateur de stockage pour gérer les rapports.

====
Vous pouvez télécharger les rapports sous forme de fichiers CSV (valeurs séparées par des virgules), Excel ou PDF.
