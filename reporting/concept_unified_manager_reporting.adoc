= Découvrez les rapports d'Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager (anciennement OnCommand Unified Manager) permet de consulter, personnaliser, télécharger et planifier des rapports pour vos systèmes de stockage ONTAP. Les rapports peuvent fournir des détails sur la capacité, l'état, les performances, la sécurité et les relations de protection du système de stockage.

La nouvelle fonctionnalité de reporting et de planification introduite dans Active IQ Unified Manager 9.6 remplace le moteur de reporting précédent qui a été abandonné dans la version 9.5 de Unified Manager.

La fonction de reporting offre différentes vues de votre réseau, fournissant des informations exploitables sur la capacité, l'état, les performances, la sécurité et les données de protection. Vous pouvez personnaliser ces vues en affichant, masquant et réorganisant les colonnes, en filtrant et triant les données, et en effectuant des recherches dans les résultats. Vous pouvez enregistrer des vues personnalisées pour les réutiliser, les télécharger sous forme de rapports et programmer leur envoi régulier par e-mail.

Vous pouvez télécharger les vues au format Microsoft® Excel et les personnaliser. Vous pouvez utiliser des fonctionnalités Excel avancées, telles que les tris complexes, les filtres multicouches, les tableaux croisés dynamiques et les graphiques. Lorsque vous êtes satisfait du rapport Excel obtenu, vous pouvez importer le fichier Excel afin de l’utiliser chaque fois que le rapport est planifié et partagé.

Outre la génération de rapports à partir de l’interface utilisateur, vous pouvez extraire de Unified Manager des données de santé, de sécurité et de performances à l’aide de ces méthodes supplémentaires :

* Utilisation de la connectivité ODBC (Open Database Connectivity) et des outils ODBC pour accéder directement à la base de données et obtenir des informations sur le cluster
* Exécution des API REST d'Unified Manager pour obtenir les informations que vous souhaitez consulter


Cette version d'Active IQ Unified Manager apporte les améliorations suivantes aux rapports :

* Un courriel contenant un rapport est envoyé selon la planification configurée. Même si vous générez un rapport à la demande, vous recevrez un courriel.
* Le nom du fichier du rapport et les métadonnées du rapport incluent le nom d'hôte à partir duquel le rapport a été généré. Grâce à cette amélioration, même si le nom du fichier est modifié, vous pouvez toujours identifier le nom d'hôte à partir duquel le rapport a été généré.
