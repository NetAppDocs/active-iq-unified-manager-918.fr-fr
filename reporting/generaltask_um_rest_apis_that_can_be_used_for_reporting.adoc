= Utilisez les API REST d'Active IQ Unified Manager pour la génération de rapports
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez utiliser les API REST pour faciliter la gestion de vos clusters en consultant les informations relatives à leur état, leur capacité, leurs performances et leur sécurité, enregistrées par Unified Manager.

Les API REST sont accessibles via la page web Swagger. Vous pouvez accéder à la page web Swagger pour afficher la documentation de l'API REST de Unified Manager, ainsi que pour effectuer manuellement un appel d'API. Dans l'interface utilisateur web de Unified Manager, dans la barre de menus, cliquez sur le bouton *Help*, puis sélectionnez *API Documentation*. Pour plus d'informations sur les API REST de Unified Manager, consultez link:../api-automation/concept_get_started_with_um_apis.html["Premiers pas avec les API REST d'Active IQ Unified Manager"].

Vous devez disposer du rôle d'opérateur, d'administrateur de stockage ou d'administrateur d'application pour accéder aux API REST.
