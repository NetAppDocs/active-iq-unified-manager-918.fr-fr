= Créez un rapport pour regrouper les relations de volume par problème dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez créer un rapport qui regroupe les relations de volume par problème.

.Avant de commencer
* Vous devez disposer du rôle Application Administrator ou Storage Administrator.


Suivez les étapes ci-dessous pour créer une vue personnalisée qui regroupe les relations de volume par problème, puis planifiez la génération d'un rapport pour cette vue.

.Étapes
. Dans le volet de navigation de gauche, cliquez sur *Stockage* > *Volumes*.
. Dans le menu Affichage, sélectionnez *Relation* > *Toutes les relations*.
. Sélectionnez *Afficher/Masquer* pour supprimer les colonnes que vous ne souhaitez pas voir apparaître dans le rapport.
. Faites glisser la colonne "`Unhealthy Reason`" près de la colonne "`State`".
. Cliquez en haut de la colonne « `Unhealthy Reason` » pour regrouper les volumes par problème.
. Enregistrez la vue sous un nom spécifique qui reflète son contenu, par exemple « `Relations Vol par problème` ».
. Cliquez sur le bouton *Rapports programmés* sur la page d'inventaire.
. Saisissez un nom pour la planification du rapport et remplissez les autres champs du rapport, puis cliquez sur la coche (image:../media/blue_check.gif[""]) à la fin de la ligne.
+
Le rapport est envoyé immédiatement à titre de test. Ensuite, le rapport est généré et envoyé par courriel aux destinataires indiqués, selon la fréquence spécifiée.



D’après les résultats présentés dans le rapport, vous pouvez analyser la source et l’impact de chaque type de problème.
