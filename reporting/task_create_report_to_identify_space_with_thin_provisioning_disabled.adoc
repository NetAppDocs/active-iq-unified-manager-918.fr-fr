= Identifiez les volumes dont le provisionnement fin est désactivé dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Lorsqu'un volume n'est pas à provisionnement fin, il occupe la totalité de l'espace sur le disque telle qu'elle a été définie lors de la création du volume. L'identification des volumes dont le provisionnement fin est désactivé vous aide à décider si vous souhaitez activer le provisionnement fin sur certains volumes.

.Avant de commencer
* Vous devez disposer du rôle Application Administrator ou Storage Administrator.


Suivez les étapes ci-dessous pour créer une vue personnalisée affichant les colonnes requises dans le bon ordre, puis planifiez la génération d'un rapport pour cette vue.

.Étapes
. Dans le volet de navigation de gauche, cliquez sur *Stockage* > *Volumes*.
. Dans le menu Affichage, sélectionnez *Capacité* > *Tous les volumes*.
. Sélectionnez *Afficher/Masquer* pour supprimer les colonnes que vous ne souhaitez pas voir apparaître dans le rapport.
. Faites glisser et déposez les colonnes « `Used Data %` » et « `Thin Provisioned` » près de la colonne « `Available Data Capacity` ».
. Cliquez sur l'icône de filtre, ajoutez le filtre suivant, *Provisionnement fin* est *Non*, puis cliquez sur *Appliquer le filtre*.
. Cliquez en haut de la colonne "`Used Data %`" pour trier les résultats afin que les volumes ayant le pourcentage le plus élevé apparaissent en haut de la liste.
. Enregistrez la vue avec un nom qui reflète ce qu’elle affiche, par exemple "`Vols no thin provisioning`".
. Cliquez sur le bouton *Rapports programmés* sur la page d'inventaire.
. Cliquez sur *Ajouter une planification* pour ajouter une nouvelle ligne à la page *Planifications des rapports* afin de définir les caractéristiques de la planification du nouveau rapport.
. Saisissez un nom pour le calendrier du rapport et remplissez les autres champs du rapport, puis cliquez sur la coche (image:../media/blue_check.gif[""]) à la fin de la ligne.
+
Le rapport est envoyé immédiatement à titre de test. Ensuite, le rapport est généré et envoyé par courriel aux destinataires indiqués, selon la fréquence spécifiée.



D’après les résultats présentés dans le rapport, vous pourriez souhaiter activer le provisionnement fin sur certains volumes.
