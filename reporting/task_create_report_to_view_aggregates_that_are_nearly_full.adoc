= Créez un rapport pour afficher les agrégats remplis à 80 % ou plus dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez créer un rapport pour mettre en évidence les agrégats remplis à 80 % ou plus.

.Avant de commencer
* Vous devez disposer du rôle Application Administrator ou Storage Administrator.


Suivez les étapes ci-dessous pour créer une vue personnalisée affichant les agrégats pleins à 80 % ou plus, puis planifiez la génération d'un rapport pour cette vue.

.Étapes
. Dans le volet de navigation de gauche, cliquez sur *Stockage* > *Agrégats*.
. Dans le menu Affichage, sélectionnez *Capacité* > *Tous les agrégats*.
. Sélectionnez *Afficher/Masquer* pour supprimer les colonnes que vous ne souhaitez pas voir apparaître dans le rapport.
. Faites glisser les colonnes "`Available Data %`" et "`Used Data %`" près de la colonne "`Aggregate`".
. Cliquez sur l'icône de filtre, ajoutez les filtres suivants, puis cliquez sur *Apply Filter* :
+
** Le pourcentage de données utilisées est supérieur à 80%


. Cliquez en haut de la colonne « `% de données utilisées` » pour trier les résultats par pourcentage de capacité.
. Enregistrez la vue avec un nom spécifique qui reflète ce que la vue affiche, par exemple « `Agrégats presque pleins` », puis cliquez sur la coche (image:../media/blue_check.gif[""]).
. Cliquez sur le bouton *Rapports programmés* sur la page d'inventaire.
. Cliquez sur *Ajouter une planification* pour ajouter une nouvelle ligne à la page Planifications des rapports afin de définir les caractéristiques de la planification du nouveau rapport.
. Saisissez un nom pour la planification du rapport et remplissez les autres champs du rapport, puis cliquez sur la coche (image:../media/blue_check.gif[""]) à la fin de la ligne.
+
Le rapport est envoyé immédiatement à titre de test. Ensuite, le rapport est généré et envoyé par courriel aux destinataires indiqués, selon la fréquence spécifiée.



D’après les résultats présentés dans le rapport, vous souhaiterez peut-être déplacer certaines données depuis certains agrégats.
