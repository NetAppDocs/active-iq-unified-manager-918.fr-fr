= Créez un rapport pour afficher les transferts de volume en fonction de la taille de transfert dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez créer un rapport pour visualiser les transferts de volume en fonction de la taille du transfert.

.Avant de commencer
* Vous devez disposer du rôle Application Administrator ou Storage Administrator.


Suivez les étapes ci-dessous pour créer une vue personnalisée des transferts de volume en fonction de la taille du transfert, puis planifiez la génération d'un rapport pour cette vue.

.Étapes
. Dans le volet de navigation de gauche, cliquez sur *Stockage* > *Volumes*.
. Dans le menu Affichage, sélectionnez *Relation* > *Taux de transfert du dernier mois*.
. Cliquez sur l’en-tête de la colonne « `Volume total transféré` » pour trier les transferts de volume par taille.
. Enregistrez la vue sous un nom spécifique qui reflète ce qu’elle affiche, par exemple "`Volumes par taille de transfert`".
. Cliquez sur le bouton *Rapports programmés* sur la page d'inventaire.
. Saisissez un nom pour la planification du rapport et remplissez les autres champs du rapport, puis cliquez sur la coche (image:../media/blue_check.gif[""]) à la fin de la ligne.
+
Le rapport est envoyé immédiatement à titre de test. Ensuite, le rapport est généré et envoyé par courriel aux destinataires indiqués, selon la fréquence spécifiée.



D’après les résultats présentés dans le rapport, vous pouvez étudier les relations entre les volumes en fonction de la taille du transfert.
