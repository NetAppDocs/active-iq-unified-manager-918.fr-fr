= Surveillez et gérez les clusters depuis le tableau de bord dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Le tableau de bord fournit des informations cumulatives en un coup d’œil sur l’état de santé actuel de vos systèmes ONTAP surveillés. Le tableau de bord fournit des "`panels`" qui vous permettent d’évaluer l’état global de la capacité, des performances et de la sécurité des clusters que vous surveillez.

De plus, certains problèmes ONTAP peuvent être résolus directement depuis l’interface utilisateur de Unified Manager au lieu d’utiliser ONTAP System Manager ou l’interface de ligne de commande ONTAP.

En haut du tableau de bord, vous pouvez choisir d'afficher les informations pour tous les clusters surveillés ou pour un cluster en particulier. Vous pouvez commencer par consulter l'état de tous les clusters, puis passer à des clusters individuels lorsque vous souhaitez afficher des informations détaillées.

[NOTE]
====
Certains des panneaux répertoriés ci-dessous peuvent ne pas apparaître sur la page en fonction de votre configuration.

====
|===
| Panneaux | Description 


 a| 
Actions de gestion
 a| 
Lorsque Unified Manager peut diagnostiquer un problème et déterminer une solution unique, cette solution est affichée dans ce panneau avec un bouton *Corriger*.



 a| 
Capacité
 a| 
Affiche la capacité totale et utilisée pour le niveau local et le niveau cloud, ainsi que le nombre de jours avant que la capacité locale n'atteigne la limite supérieure.



 a| 
Capacité de performance
 a| 
Affiche la valeur de capacité de performance pour chaque cluster et le nombre de jours restants avant que cette capacité n'atteigne la limite supérieure.



 a| 
IOPS du workload
 a| 
Affiche le nombre total de workloads actuellement exécutés dans une certaine plage d'IOPS.



 a| 
Performances du workload
 a| 
Affiche le nombre total de workloads conformes et non conformes affectés à chaque niveau de service de performance défini.



 a| 
Sécurité
 a| 
Affiche le nombre de clusters conformes ou non conformes, le nombre de SVM conformes ou non conformes et le nombre de volumes chiffrés ou non chiffrés.



 a| 
Protection
 a| 
Affiche le nombre de machines virtuelles de stockage protégées par une relation SVM-DR, de volumes protégés par une relation SnapMirror, de volumes protégés par Snapshot et de clusters protégés par MetroCluster.



 a| 
Aperçu de l'utilisation
 a| 
Affiche les clusters triés par nombre d'IOPS le plus élevé, débit le plus élevé (MBps) ou capacité physique utilisée la plus élevée.

|===
