= Ajoutez vos rubriques d'aide favorites à vos favoris dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Dans l'onglet Favoris de l'aide, vous pouvez ajouter à vos favoris les rubriques d'aide que vous consultez fréquemment. Les signets d'aide permettent d'accéder rapidement à vos rubriques favorites.

.Étapes
. Accédez à la rubrique d'aide que vous souhaitez ajouter à vos favoris.
. Cliquez sur *Favoris*, puis sur *Ajouter*.
