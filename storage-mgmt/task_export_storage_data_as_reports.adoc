= Exportez les données de stockage sous forme de rapports dans Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez exporter les données de stockage dans différents formats de sortie, puis utiliser les données exportées pour créer des rapports. Par exemple, si 10 événements critiques n'ont pas été résolus, vous pouvez exporter les données depuis la page d'inventaire de la gestion des événements afin de créer un rapport, puis l'envoyer aux administrateurs qui pourront résoudre les problèmes.

Vous pouvez exporter des données vers un fichier `.csv`, un fichier `.xlsx` ou un document `.pdf` depuis les pages d'inventaire *Storage* et *Network*, puis utiliser les données exportées pour créer des rapports. Il existe d'autres emplacements dans le produit où seuls des fichiers `.csv` ou `.pdf` peuvent être générés.

.Étapes
. Effectuez l'une des actions suivantes :
+
|===
| Si vous souhaitez exporter... | Faites ceci... 


 a| 
Détails de l’inventaire des objets de stockage
 a| 
Dans le menu de navigation de gauche, cliquez sur *Stockage* ou *Réseau*, puis sélectionnez un objet de stockage. Choisissez l’une des vues fournies par le système, ou toute vue personnalisée que vous avez créée.



 a| 
Détails du groupe de stratégie QoS
 a| 
Cliquez sur *Stockage* > *QoS Policy Groups* dans le menu de navigation de gauche.



 a| 
Détails sur la capacité de stockage et l'historique de protection
 a| 
Cliquez sur *Storage* > *Aggregates* ou *Storage* > *Volumes*, puis sélectionnez un seul agrégat ou volume.



 a| 
Détails de l'événement
 a| 
Cliquez sur *Gestion des événements* dans le menu de navigation de gauche.



 a| 
Détails des 10 principales performances de l'objet de stockage
 a| 
Cliquez sur *Storage* > *Clusters* > *Performance:All Clusters*, puis sélectionnez un cluster et choisissez l’onglet *Top Performers*. Sélectionnez ensuite un objet de stockage et un compteur de performances.

|===
. Cliquez sur le bouton *Reports* (ou sur le bouton *Export* sur certaines pages UI).
. Cliquez sur *Télécharger CSV*, *Télécharger PDF* ou *Télécharger Excel* pour confirmer la demande d'exportation.
+
Dans l'onglet « Top Performers », vous pouvez choisir de télécharger un rapport des statistiques pour le cluster unique que vous consultez ou pour tous les clusters du centre de données.

+
Le fichier a été téléchargé.

. Ouvrez le fichier dans l'application appropriée.
